4.4.2.5
SB-RMI Alert
The processor alerts the SBI when a Machine Check Exception occurs within the system. The Machine Check Exception 
status is reflected in registers SBRMI_x01[F:0].
The processor alerts the SBI on system fatal error event. This status is reflected in SBRMI_x02[SwAlertSts]. To enable 
this functionality, SBRMI_x01[SwAlertMask] must be clear.
