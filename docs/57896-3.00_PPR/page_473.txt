SB Temperature Sensor Interface (SB-TSI)
5.1
Overview
The SBI temperature sensor interface (SB-TSI) is an emulation of the software and physical interface of a typical 8-pin 
remote temperature sensor (RTS), see Figure 25 [RTS Thermal Management Example]. The goal is to resemble a typical
RTS so that KBC or BMC firmware requires minimal changes for future AMD products, see Figure 26 [SB-TSI Thermal 
Management Example]. SB-TSI supports the SMBus protocols that typical RTS supports.
