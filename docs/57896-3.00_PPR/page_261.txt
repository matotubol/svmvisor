PMCx00C [FP uops retired sorted by packed 128 or packed 256] 
(Core::X86::Pmc::Core::Packed_FP_Ops_Retired)
Read-write. 
Number of FP uops retired of selected type sorted by 128-bit packed dest (XMM) or 256-bit packed dest (YMM). Can be
used to profile FP codes.
