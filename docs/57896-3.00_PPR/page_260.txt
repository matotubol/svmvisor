PPR for AMD Family 1Ah Model 44h B0
PMCx00B [FP executed integer type uops sorted by vector or scalar] (Core::X86::Pmc::Core::INT_Ops_Retired)
Read-write. 
Number of integer uops executed in the FP retired of selected type sorted by vector (SSE/AVX) or scalar (MMX). Can 
be used to profile vector INT / MMX codes.
