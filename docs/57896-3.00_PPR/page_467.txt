4.5
SBI Physical Interface
4.5.1
SBI SMBus Address
The SMBus address is really 7 bits. Some vendors and the SMBus specification show the address as 8 bits: bits[7:1] as the
left-justified address, and bit[0] as the Read/Write flag, where 0 indicates a Write and 1 indicates a Read. Some vendors 
use only the 7 bits to describe the address.
4.5.2
SBI Bus Timing
SBI supports 100KHz standard-mode and 400 KHz fast-mode I2C operation. Refer to the standard-mode and fast-mode 
timing parameters in the I2C specification.
