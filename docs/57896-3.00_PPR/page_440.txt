Read-only. Reset: Cold,0000_0000_0000_0000h. 
The MCA::KPX::GMI::MCA_DEADDR_KPX_GMI register stores the address associated with the error in 
MCA::KPX::GMI::MCA_DESTAT_KPX_GMI. The register is only meaningful if 
MCA::KPX::GMI::MCA_DESTAT_KPX_GMI[Val]=1 and MCA::KPX::GMI::MCA_DESTAT_KPX_GMI[AddrV]=1.
