PMCx0D6 [Cycles with no retire] (Core::X86::Pmc::Core::Cycles_With_No_Retire)
Read-write. 
This event counts cycles when the hardware thread does not retire any ops for reasons selected by UnitMask[4:0]. 
UnitMask events [4:0] are mutually exclusive. If multiple reasons apply for a given cycle, the lowest numbered 
UnitMask event is counted.
