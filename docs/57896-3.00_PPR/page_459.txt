SB-RMI Read Processor Register and Read CPUID Commands
SB-RMI read processor register and read CPUID commands are performed using the SBI Modified Block Write-Block 
Read Process Call. If an SMBus timeout occurs before the data is returned, a read data/status can be issued to read the 
data from the previous command. The previous command must be complete before a new command can be issued.
