1.3.2.1
Searching a Multiple Volume PPR
The PPR is a multiple PDF document and searching all PDFs is performed as follows:
•
The zip of PDF files must be extracted to a directory where the search will be performed. A search across multiple
PDF files can not be performed from within a zip of PDF's.
•
Open search by selecting Menu->Search->Advanced Search (Shift+Ctrl+F)
•
Select "All PDF Documents in" and select "Browse for Location...", which opens the "Browse For Folder" 
window.
•
In the "Browse For Folder" window, select the folder that contains the PPR PDFs that need to be searched, and 
select OK.

1.3.2.2
Cross-References and Hyperlinks
A cross-reference is a link to a location within the same PDF. A hyperlink is a link to a location within a different PDF.
•
For cross-references, use "Previous View" to return from the current location to the previous location.
•
Menu->View->Page Navigation->Previous View
•
Hyperlinks between documents leave the current location unchanged in the PDF that contained the hyperlink.
•
In order for hyperlinks to work properly the zip of PDF's must be extracted to a directory. Hyperlinks will not 
function within a zip of PDF's.
