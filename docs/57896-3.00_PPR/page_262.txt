PPR for AMD Family 1Ah Model 44h B0
PMCx00D [FP executed packed integer uops sorted by packed 128 or packed 256] 
(Core::X86::Pmc::Core::Packed_INT_Ops_Retired)
Read-write. 
Number of integer uops executed in FP retired of selected type sorted by 128-bit packed dest (XMM) or 256-bit packed 
dest (YMM). Can be used to profile FP codes.
