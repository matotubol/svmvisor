PMCx00A [FP uops retired sorted by vector or scalar] (Core::X86::Pmc::Core::FP_Ops_Retired)
Read-write. 
Number of FP uops retired of selected type sorted by vector (AVX/SSE packed) or scalar (x87, AVX/SSE scalar). Can be
used to profile FP codes.
