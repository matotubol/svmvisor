1. This notation specifies that bit[47] is replicated in each of the 16 MSBs of the DW (sometimes called sign 
extended). The 16 LSBs contain bits[47:32].
2. Only used for an SMI in guest mode with nested paging enabled.
The SMI save state includes most of the integer execution unit. Not included in the save state are: the floating-point state, 
MSRs, and CR2. In order to be used by the SMI handler, these must be saved and restored. The save state is the same, 
regardless of the operating mode (32-bit or 64-bit).
