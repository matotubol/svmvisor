(MCA::KPX::GMI::MCA_CTL_KPX_GMI)
Read-write. Reset: 0000_0000_0000_0000h. 
0=Disables error reporting for the corresponding error. 1=Enables error reporting via machine check exception for the 
corresponding error. The MCA::KPX::GMI::MCA_CTL_KPX_GMI register must be enabled by the corresponding 
enable bit in Core::X86::Msr::MCG_CTL. Does not affect error detection, correction, or logging.
