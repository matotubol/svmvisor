11.4.21 _TSN (Thermal Sensor Device)
This object, when defined under a thermal zone, returns a reference to the thermal sensor device used to monitor the
temperature of the thermal zone. See Native OS Device Driver Thermal Interfaces.
Arguments:
None
Return Value:
A single Reference to the namespace device object that monitors the temperature of the thermal zone.
11.4.22 _TSP (Thermal Sampling Period)
This object evaluates to a thermal sampling period (in tenths of seconds) used by OSPM to implement the Passive
cooling equation. This value, along with _TC1 and _TC2, will enable OSPM to provide the proper hysteresis required
by the system to accomplish an effective passive cooling policy.
Arguments:
None
Return Value:
An Integer containing the sampling period in tenths of seconds
