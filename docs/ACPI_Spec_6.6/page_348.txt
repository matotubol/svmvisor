Has the device encountered any issues? This allows any agent
parsing this record to understand in whether or not the device is
healthy without needing to parse the device-specific health data.
Any device health state may expose device-specific data:
0 = Errors found
1 = No errors found
2 = Unknown
3 = Advisory - additional device-specific data exposed
The Reset Reason should set this value to ‘1’ (no error) for
expected resets/boots, and ‘0’ (error) for unexpected conditions.
