Base
Integer (QWORD)
64-bit memory address of the Host Bridge Register block:
If Version = 0, this represents the base address of CXL 1.1
downstream port RCRB
If Version = 1, this represents the base address of the CXL 2.0 Host
Bridge Component Registers (CHBCR)
Length
Integer (DWORD)
Length of the Host Bridge Register Block in bytes:
If Version = 0, this field must be set to 8 KB (0x2000)
If Version = 1, this field must be set to 64 KB (0x10000)
Note: Links to the CXL 1.1 and CXL 2.0 Specifications can be found at http://uefi.org/acpi, under the corresponding
headings for each spec.
