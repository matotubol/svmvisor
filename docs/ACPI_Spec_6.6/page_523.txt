6.4.3.6 Extended Interrupt Descriptor
Type 1, Large Item Value 0x9
The Extended Interrupt Descriptor is necessary to describe interrupt settings and possibilities for systems that support
interrupts above 15.
To specify multiple interrupt numbers, this descriptor allows vendors to list an array of possible interrupt numbers, any
one of which can be used.
