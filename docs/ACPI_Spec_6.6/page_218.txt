5.2.12.16 GIC MSI Frame Structure
Each GICv2m MSI frame consists of a 4k page which includes registers to generate message signaled interrupts to
an associated GIC distributor. The frame also includes registers to discover the set of distributor lines which may be
signaled by MSIs from that frame. A system may have multiple MSI frames, and separate frames may be defined for
secure and non-secure access. This structure must only be used to describe non-secure MSI frames.
