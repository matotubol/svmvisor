5.2.21.2 Memory RAS Features – Feature Type 0
Memory RAS features apply to RAS capabilities, controls and operations that are specific to memory. These features
might be provided through one or more PCC sub-spaces. RAS2 sub-spaces for memory-specific RAS features have a
Feature Type of 0x00 (Memory).
