Advanced Configuration and Power Interface (ACPI) Specification, Release 6.6
A.11.3 Storage Device Wake Events
Storage devices with removable media can, optionally, signal wake upon insertion of media using their bus-specific
notification mechanism. There are no other wake events defined for Storage devices.
A.11.4 Storage Device Minimum Power Capabilities
A hard disk, CD-ROM or IDE/ATAPI removable storage device conforming to this specification must support the D0
and D3 states. Support for the D1 state is optional.
A floppy disk and IDE channel device conforming to this specification must support the D0 and D3 states.
