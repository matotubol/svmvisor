If the value of source_event is 0x100 or greater then the OSPM status indication is a result of an OSPM action as
indicated in OST Source Event Codes. For example, a value of 0x103 will be passed into _OST for this argument upon
the failure of a user interface invoked device ejection.
If OSPM is unable to identify the originating notification value, OSPM invokes _OST with a value that contains all
bits set (ones) for this parameter.
Arg1 – Status Code: DWordConst. OSPM indicates a notification value specific status. See Table 6.22, Table 6.23,
and Table 6.25 for status code descriptions.
Arg2 - A buffer containing detailed OSPM-specific information about the status indication. This argument may be null.
