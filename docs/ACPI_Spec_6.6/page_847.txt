12.9.2.5 Write Byte
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_CMD:
Command byte to be sent.
SMB_DATA[0]:
Data byte to be sent.
SMB_PRTCL:
Write 0x06 to initiate the write byte protocol, or 0x86 to initiate the write byte protocol with
PEC.
Data Returned:
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
12.9.2.6 Read Byte
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_CMD:
Command byte to be sent.
SMB_PRTCL:
Write 0x07 to initiate the read byte protocol, or 0x87 to initiate the read byte protocol with PEC.
Data Returned:
SMB_DATA[0]:
Data byte received.
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
12.9.2.7 Write Word
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_CMD:
Command byte to be sent.
SMB_DATA[0]:
Low data byte to be sent.
SMB_DATA[1]:
High data byte to be sent.
SMB_PRTCL:
Write 0x08 to initiate the write word protocol, or 0x88 to initiate the write word protocol with
PEC.
Data Returned:
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
