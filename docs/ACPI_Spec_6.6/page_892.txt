15.5 Example Address Map
This sample address map (for an Intel processor-based system) describes a machine that has 128 MiB of RAM, 640
KiB of base memory and 127 MiB of extended memory. The base memory has 639 KiB available for the user and
1 KiB for an extended BIOS data area. A 4-MiB Linear Frame Buffer (LFB) is based at 12 MiB. The memory hole
created by the chip set is from 8 MiB to 16 MiB. Memory-mapped APIC devices are in the system. The I/O Unit is at
FEC00000 and the Local Unit is at FEE00000. The system BIOS is remapped to 1 GB-64 KiB.
The 639-KiB endpoint of the first memory range is also the base memory size reported in the BIOS data segment at
40:13. The following table shows the memory map of a typical system.
