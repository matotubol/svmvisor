8.4.1.2 _CSD (C-State Dependency)
This optional object provides C-state control cross logical processor dependency information to OSPM. The _CSD
object evaluates to a packaged list of information that correlates with the C-state information returned by the _CST
object. Each packaged list entry identifies the C-state for which the dependency is being specified (as an index into the
_CST object list), a dependency domain number for that C-state, the coordination type for that C-state and the number
of logical processors belonging to the domain for the particular C-state. It is possible that a particular C-state may
belong to multiple domains. That is, it is possible to have multiple entries in the _CSD list with the same CStateIndex
value.
Arguments:
None
Return Value:
A variable-length Package containing a list of C-state dependency Packages as described below.
