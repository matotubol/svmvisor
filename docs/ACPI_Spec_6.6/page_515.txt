6.4.3.5.3 Word Address Space Descriptor
Type 1, Large Item Value 0x8
The WORD address space descriptor is used to report resource usage in a 16-bit address space (like memory and I/O).
ò Note
This descriptor is exactly the same as the DWORD descriptor specified in End Dependent Functions Descriptor;
the only difference is that the address fields are 16 bits wide rather than 32 bits wide.
