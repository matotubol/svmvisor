9.18 Generic Buttons Device
The-Generic-Button device is a standard device for reporting button events via hardware interrupts, and mapping those
interrupts to specific usages defined in the Human Interface Device (HID) specification. In order to express the func-
tionality of a button to the OS, two pieces of information are required: Usage of the HID Control, and Usage of the
HID Collection that the Control belongs to. A Usage is a combination of a Usage Page and Usage ID. For example, the
Volume Up button is identified as the Volume Up Usage (Usage Page 0x0C, Usage Id 0xE9) in the Consumer Control
Collection (Usage Page 0x0C, Usage Id 0x01).
The Plug and Play ID of the Generic Button device is ACPI0011.
ò Note
If the Power button is described using this device, it must also support the Power Button Override feature defined
in Section 4.8.2.2.1.3.
