5.2.27.3 Device configuration space
Body of ‘Capabilities’ field in Configuration space structure. The device configuration layout differs depending on
the byte array size, whether it is 1, 2, 3 or more. I2S-transfer is described by either by generic structure composed of
VirtualSlot and ConfigType or VirtualSlot alone. In the latter case, the kernel driver must assume ConfigType of default
value 0. PDM-transfer descriptor varies depending on the number of microphones and complexity of their layout.
union DeviceConfig {
u8 VirtualSlot;
// if CapabilitiesSize = 1
struct {
u8 VirtualSlot;
u8 ConfigType;
} Gen;
// if CapabilitiesSize = 2
struct {
u8 VirtualSlot;
u8 ConfigType;
u8 ArrayType;
} Mic;
// if CapabilitiesSize = 3
struct {
u8 VirtualSlot;
u8 ConfigType;
u8 ArrayType;
u8 MicsCount;
VendorMicConfig Mics[]
} VendorMic;
// if CapabilitiesSize > 3
};
