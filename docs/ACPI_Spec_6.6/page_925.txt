18.3.2.6 PCI Express/PCI-X Bridge AER Structure
PCI Express/PCI-X bridges that implement AER support implement fields that control the behavior how errors are
reported across the bridge.
The HEST may contain one entry of this type for each PCI Express/PCI-X bridge if none of the entries has the GLOBAL
flag set. If the GLOBAL flag is set, there may only be one entry of this type and the information contained in that entry
will be applied to all PCI Express/ PCI-X bridges.
