6.2.19 _HMA(Heterogeneous Memory Attributes)
The Heterogeneous Memory Attributes Table (HMAT) defined in Heterogeneous Memory Attribute Table (HMAT)
provides Heterogeneous Memory Attributes. Dynamic runtime reconfiguration of the system may cause proximities
domains or memory attributes to change. If the “Reservation Hint” is set, new HMAT update shall not reset the
“Reservation Hint” unless the memory range is removed.
_HMA is an optional object that enables the platform to provide the OS with updated Heterogeneous Memory Attributes
information at runtime. _HMA provides OSPM with the latest HMAT in entirety overriding existing HMAT.
Arguments:
None
Return Value:
A Buffer containing entire HMAT.
