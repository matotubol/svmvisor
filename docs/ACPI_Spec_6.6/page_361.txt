5.2.39 Hart Info Node Structure
This structure shall be provided once for each hart. To match with the processor device in the name space, each structure
will have the ACPI processor UID.
This structure should be populated in the RHCT node array after all other types of RHCT nodes are populated since it
references other RHCT nodes.
