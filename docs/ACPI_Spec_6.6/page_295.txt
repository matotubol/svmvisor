5.2.25.2 Arm Generic Watchdog Structure
The Arm Generic Watchdog is a Platform GT with built-in support for use as the Watchdog timer on platforms compliant
with the Server Base System Architecture (SBSA) or Base System Architecture (BSA). For more information, see Links
to ACPI-Related Documents under the heading Arm Base System Architecture (BSA).
