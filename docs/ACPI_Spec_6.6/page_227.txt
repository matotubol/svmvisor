5.2.12.27 RISC-V Interrupt Controller (RINTC) Structure
The RISC-V platforms need to have a simple, per-hart (hardware thread or logical processor) interrupt controller avail-
able to supervisor mode. Each hart in the system is required to have a RINTC record in the MADT, and a processor
device object in the DSDT.
All the RINTCs should be probed by the OSPM before any other interrupt controllers.
For RISC-V platforms, the “Local Interrupt Controller Address” field in the MADT must be ignored by the OSPM.
