Resource Connection Instance. If the device specified in the Resource Source
field in this structure supports more than one connection (e.g. port), this field
describes the instance of the connection to which this Device is connected.
Byte 5
Serial Bus Type
Indicates which type of serial bus connection this descriptor describes. Defined
values are:
0 - Reserved
1 - I2C
2 - SPI
3 - UART
4 - CSI-2
5-191 - Reserved
192-255 - Hardware Vendor Defined
Byte 6
General Flags [7:0]
Flags that are common to all serial bus connection types:
Bits[7:3] Reserved. Must be 0.
Bit[2] Connection Sharing, _SHR:
0x0: Exclusive: This Serial Bus connection is used exclusively by one
device. If Serial Bus Type is CSI, UART, or SPI then Bit 2 must be 0.
Bit[1] Consumer/Producer:
0x1: This device consumes this resource
0x0: This device produces and consumes this resource
Bit[0] Slave Mode:
0x1: The communication over this connection is initiated by the device.
0x0: The communication over this connection is initiated by the
controller.
