Component ID definition depends on the EINJv2 Error Type.
- Processor Error (0x1):
The lower 32 bits represent the ACPI UID of the processor,
as represented in MADT. The remaining bits are vendor
specific.
- Memory Error (0x2):
This represents the Device ID within the memory module
(e.g., DDR DIMM) for a particular system physical address.
For example: 18 x 4 DIMMs support up to 18 devices (0-17)
per address. 9 x 8 DIMMs support up to 9 devices (0-8) per
address. It is possible to inject error syndrome into multiple
devices.
- PCIe Error (0x4):
The lower 32 bits represent the SBDF, encoded like the PCIe
SBDF field in Table 18.31. The remaining bits are vendor
specific.
