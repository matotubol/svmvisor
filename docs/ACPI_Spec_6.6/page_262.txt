5.2.21.2.3 Address Translation Service
The platform can use this feature to provide support for translation of physical addresses to logical addresses and vice
versa.
The translation to logical addresses is required when the OSPM intends to inject an error on a component using the local
view of memory of that component. The translation of logical address to physical address is required when OSPM only
has the capability to inject an error using physical address but wants to target specific locations on a memory component.
