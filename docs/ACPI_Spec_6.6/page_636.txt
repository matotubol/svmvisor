8.4.5.5 _PSD (P-State Dependency)
This optional object provides performance control, P-state or CPPC, logical processor dependency information to
OSPM. The _PSD object evaluates to a packaged list containing a single entry that expresses the performance con-
trol dependency among a set of logical processors.
Arguments:
None
Return Value:
A Package with a single entry consisting of a P-state dependency Package as described below.
Return Value Information
Package {
PStateDependency[0]
// Package
}
The PStateDependency sub-Package contains the elements described below:
Package {
NumEntries
// Integer
Revision
// Integer (BYTE)
Domain
// Integer (DWORD)
CoordType
// Integer (DWORD)
NumProcessors
// Integer (DWORD)
}
