Bit
Name
Description
0
Enabled
If clear, the OSPM ignores this Memory Power Node Structure. This al-
lows system firmware to populate the MPST with a static number of struc-
tures but enable them as necessary.
1
Power Managed Flag
1 - Memory node is power managed
0 - Memory node is not power managed. For non power managed node,
OSPM shall not attempt to transition node into low power state. System
behavior is undefined if OSPM attempts this. NOTE: If the memory
range corresponding to the memory node includes platform firmware
reserved memory that cannot be power managed, the platform should
indicate such memory as “not power managed” to OSPM. This allows
OSPM to ignore such ranges from its power optimization.
