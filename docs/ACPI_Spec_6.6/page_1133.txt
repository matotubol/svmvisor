20.2.4 Package Length Encoding
PkgLength :=
PkgLeadByte |
<pkgleadbyte bytedata> |
<pkgleadbyte bytedata bytedata> |
<pkgleadbyte bytedata bytedata bytedata>
PkgLeadByte :=
<bit 7-6: bytedata count that follows (0-3)>
<bit 5-4: only used if pkglength <= 63>
<bit 3-0: least significant package length nybble>
ò Note
The high 2 bits of the first byte reveal how many follow bytes are in the PkgLength. If the PkgLength has only one
byte, bit 0 through 5 are used to encode the package length (in other words, values 0-63). If the package length value
is more than 63, more than one byte must be used for the encoding in which case bit 4 and 5 of the PkgLeadByte
are reserved and must be zero. If the multiple bytes encoding is used, bits 0-3 of the PkgLeadByte become the least
significant 4 bits of the resulting package length value. The next ByteData will become the next least significant 8
bits of the resulting value and so on, up to 3 ByteData bytes. Thus, the maximum package length is 2*28.
