5.2.34 Miscellaneous GUIDed Table Entries
This section describes a means by which a platform can expose data through a GUIDed entry through a single well-
known MISC table signature. The MISC table and each GUIDed entry is defined sufficiently in this specification to
allow for the discovery of the MISC table and walking the GUIDed entries that it may contain. The format of the data
within each GUIDed entry is vendor specific and defined by the Entry GUID ID.
GUIDs in the MISC table shall meet the following expectations:
1. There is no requirement to register a GUID that’s used in an MISC table entry.
2. Optionally, GUIDs in the MISC table can be registered using the same process are ACPI table signatures.
