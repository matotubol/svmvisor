5.2.35 CC Event Log ACPI Table
This section describes the format of the confidential computing (CC) event log ACPI table. A virtual firmware with
CC capability may set up an ACPI table to pass the CC event log information. The event log created by the virtual
firmware owner contains the hashes to reconstruct the CC measurement registers.
