19.3.1.1 _T_x Reserved Object Names
The ACPI specification reserves object names with the prefix _T_ for internal use by the ASL compiler. The ASL
compiler may, for example, use these objects to store temporary values when implementing translation of complicated
control structures into AML. The ASL compiler must declare _T_x objects normally (using Name) and must not define
them more than once within the same scope.
