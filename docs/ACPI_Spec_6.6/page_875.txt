Contains the processor relative address, represented in Generic Address
Structure (GAS) format, of the platform interrupt acknowledge register.
Note: Only the System I/O, System Memory, and Functional Fixed Hard-
ware spaces are valid for values for Address_Space_ID. If the subspace
does not support interrupts or the interrupt is edge driven the register may
be omitted. A value of 0x0 on all 12 bytes of the GAS structure indicates
the register is not present. If the subspace does support interrupts, and
these are level, this register must be supplied. And is used to clear the
interrupt by using a read, modify, write sequence.
