Arg2 - A 4-byte buffer that represents a DWORD that is the number of logical processors that are now
idled)
The platform may request a number of logical processors to be idled that exceeds the available number of logical
processors that can be idled from an OSPM context for the following reasons:
• The requested number is larger than the number of logical processors currently defined.
• Not all the defined logical processors were onlined by the OS (for example. for licensing reasons)
Logical processors critical to OS function (for example, the BSP) cannot be idled.
