18.3.2.2 IA-32 Architecture Corrected Machine Check
Processors implementing the IA-32 Instruction Set Architecture may report corrected processor errors to OSPM. The
information in this table allows platform firmware to communicate key parameters of the corrected processor error
reporting mechanism to OSPM, including whether CMC processing should be enabled.
Only one entry of this type is permitted in the HEST. OSPM applies the information specified in this entry to all
processors.
