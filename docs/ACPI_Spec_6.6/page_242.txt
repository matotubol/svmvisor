5.2.16.7 Generic Port Affinity Structure
The Generic Port Affinity Structure provides an association between a proximity domain number and a device handle
representing a Generic Port (e.g. CXL Host Bridge, or similar device that hosts a dynamic topology of memory ranges
and/or initiators).
Support of Generic Port Affinity Structures by an OSPM is optional.
