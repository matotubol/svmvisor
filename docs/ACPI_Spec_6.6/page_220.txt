This field specifies if the associated GIC Redistributors are
cache coherent with the CPU. The values for this flag are:
0x0: The Redistributors are fully coherent. OSPM does not
need to perform any Cache Maintenance on the associated
tables in memory if the appropriate cacheability and
shareability attributes have been configured in the
Redistributors.
0x1: The Redistributors are not coherent. OSPM needs to
perform cache maintenance on the associated tables in
memory.
Note: If there are multiple GICR structures present in
MADT, then all the GICR structures must have the same
value for this flag.
