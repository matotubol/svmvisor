5.2.27 Non HDAudio Link Table (NHLT)
Audio data can be transferred over many different interfaces: HDAudio, I2S, PDM and more. Process of configuring
such transfer differs between the interfaces. In I2S and PDM case, the kernel driver does not have access to relevant
hardware registers to program the underlying hardware. The necessary data must be then provided to the AudioDSP
firmware which will do the programming on driver’s behalf. NHLT helps facilitate that process.
The NHLT table is comprised of standard ACPI table header followed by list of endpoint descriptors, one for each
non-HDAudio endpoint to be supported in the userspace.
