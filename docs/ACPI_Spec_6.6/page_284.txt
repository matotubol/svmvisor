A set of FPDT Performance Records, as defined in Table 5.122
5.2.24.1 Performance Record Format
A performance record is comprised of a sub-header including a record type and length, and a set of data. The format
of the data is specific to the record type. In this manner, records are only as large as needed to contain the specific type
of data to be conveyed.
Note that unless otherwise specified, multiple records are permitted for a given type, because some events may occur
multiple times during the boot process.
