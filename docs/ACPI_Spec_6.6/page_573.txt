It is important to note that OSPM does not evaluate the _IRC object. It has no defined input arguments nor does it
return any value. OSPM derives meaning simply from the existence of the _IRC object.
7.3.16 _S1D (S1 Device State)
This object evaluates to an integer that conveys to OSPM the shallowest D-state supported by this device in the S1
system sleeping state. _S1D must return the same integer each time it is evaluated. This value overrides an S-state to
D-state mapping OSPM may ascertain from the device’s power resource declarations. See PSC Device State Codes for
valid return values.
Arguments:
None
Return Value:
An Integer containing the shallowest D-state supported in state S2
If the device can wake the system from the S1 system sleeping state (see _PRW) then the device must support wake in the
D-state returned by this object. However, OSPM cannot assume wake from the S1 system sleeping state is supported
in any deeper D-state unless specified by a corresponding _S1W object. The table below provides a mapping from
Desired Actions to Resultant D-state entered based on the values returned from the _S1D, _PRW, and _S1W objects if
