5.2.27.1 Endpoint descriptor
Each descriptor provides general information about the endpoint. It is followed by description of the device that ex-
poses the endpoint (see Section 5.2.27.3) and configuration data that helps program the hardware for all audio formats
supported by the endpoint (see Section 5.2.27.4). Secondary device information (see Section 5.2.27.5) may optionally
tail the descriptor.
