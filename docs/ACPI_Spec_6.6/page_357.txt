5.2.36 Storage Volume Key Location Table
This section describes the format of the confidential computing (CC) storage volume key location ACPI table. In the
CC environment, the storage volume will typically be an encrypted volume. In that case, the virtual firmware may need
to support quote generation and attestation to be able to fetch a set of storage-volume key(s) from a remote-key server
during boot and pass the key to the guest kernel. Typically, the key is stored in memory, and the information of the key
is passed from virtual firmware via an ACPI table.
