Advanced Configuration and Power Interface (ACPI) Specification, Release 6.6
Return Value: A Package of Packages. The outer package must contain a Type field, (integer) followed by a sequence
of firmware inventory packages, each representing a firmware image.
The type field determines the layout of the firmware inventory packages.
Below is the list of supported firmware inventory layouts as a function of type.
Type 0 (subset of SMBIOS type 45):
• Handle (Integer). This value references the SMBIOS Type 45 Handle value in the SMBIOS table matching this
entry.
• Firmware Component Name
• Firmware Version (String)
• Firmware Release Date (String)
• Lowest Supported Firmware Version (String)
• Image Size (Integer)
All fields above are formatted as defined in the SMBIOS Specification. Other entries within each SMBIOS Table Type
45 Structure are unchanged.
For invalid values of Arg3, Package () {Zero} is returned.
