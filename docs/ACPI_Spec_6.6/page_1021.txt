19.6 ASL Operator Reference
This section describes each of the ASL operators. The syntax for each operator is given, with a description of each
argument and an overall description of the operator behavior. Example ASL code is provided for the more complex
operators.
ASL operators can be categorized as follows:
• Named Object creation
• Method execution control (If, Else, While, etc.)
• Integer math
• Logical operators
• Resource Descriptor macros
• Object conversion
• Utility/Miscellaneous
