7.3.18 _S3D (S3 Device State)
This object evaluates to an integer that conveys to OSPM the shallowest D-state supported by this device in the S3
system sleeping state. _S3D must return the same integer each time it is evaluated. This value overrides an S-state to
D-state mapping OSPM may ascertain from the device’s power resource declarations. See PSC Device State Codes for
valid return values.
Arguments:
None
Return Value:
An Integer containing the shallowest D-state supported in state S3
If the device can wake the system from the S3 system sleeping state (see _PRW) then the device must support wake in the
D-state returned by this object. However, OSPM cannot assume wake from the S3 system sleeping state is supported
in any deeper D-state unless specified by a corresponding _S3W object. The table below provides a mapping from
