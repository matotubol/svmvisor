12.9.2.2 Read Quick
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_PRTCL:
Write 0x03 to initiate the read quick protocol.
Data Returned:
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
12.9.2.3 Send Byte
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_CMD:
Command byte to be sent.
SMB_PRTCL:
Write 0x04 to initiate the send byte protocol, or 0x84 to initiate the send byte protocol with PEC.
Data Returned:
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
12.9.2.4 Receive Byte
Data Sent:
SMB_ADDR:
Address of SMBus device.
SMB_PRTCL:
Write 0x05 to initiate the receive byte protocol, or 0x85 to initiate the receive byte protocol with
PEC.
Data Returned:
SMB_DATA[0]:
Data byte received.
SMB_STS:
Status code for transaction.
SMB_PRTCL:
0x00 to indicate command completion.
