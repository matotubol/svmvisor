5.2.24.4 Host Firmware Boot Performance Table Pointer Record
The Host Firmware Boot Performance Table Pointer Record contains a pointer to the Firmware Basic Boot Performance
Table. The Firmware Basic Boot Performance Table itself exists in a range of memory described as ACPI Address-
RangeReserved in the system memory map. The record pointer is a required entry in the FPDT for any system, and the
pointer must point to a valid static physical address. Only one of these records will be produced.

5.2.24.5 S3 Performance Table Pointer Record
The S3 Performance Table Pointer Record contains a pointer to the S3 Performance Table. The S3 Performance Table
itself exists in a range of memory described as ACPI AddressRangeReserved in the system memory map. The record
pointer is a required entry in the FPDT for any system supporting the S3 state, and the pointer must point to a valid
static physical address. Only one of these records will be produced.

5.2.24.6 Microcontroller Boot Performance Table Pointer Record
The Microcontroller Boot Performance Table Pointer contains a pointer to the Microcontroller Boot Performance Table.
The Microcontroller Boot Performance Table itself exists in a range of memory described as ACPI AddressRangeRe-
served in the system memory map. The record pointer is a required entry in the FPDT for any system, and the pointer
must point to a valid static physical address. Only one of these records will be produced.
