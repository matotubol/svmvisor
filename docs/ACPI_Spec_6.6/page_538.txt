Flags [7:0]

Bit [0] - IO Sharing, _SHR
0x0 = Exclusive: This function is

0x1 = Shared: This function is shared

Flags [15:8]
Reserved. Must be 0.

Pin pull configuration
Can be one of PullDefault, PullUp, Pull-
Down, PullNone or a vendor-supplied value
in the range 128-255.

The function number in which the pin is con-
figured. This number is provider-specific.

The function number in which the pin is con-

The offset is relative to the start of this de-
