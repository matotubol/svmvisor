6.4 Resource Data Types for ACPI
The _CRS, _PRS, and _SRS control methods use packages of resource descriptors to describe the resource requirements
of devices.
6.4.1 ASL Macros for Resource Descriptors
ASL includes some macros for creating resource descriptors. The ASL syntax for these macros is defined in ASL
Operator Reference, along with the other ASL operators.

6.4.2.1 IRQ Descriptor
Type 0, Small Item Name 0x4, Length = 2 or 3
The IRQ data structure indicates that the device uses an interrupt level and supplies a mask with bits set indicating the
levels implemented in this device. For standard PC-AT implementation there are 15 possible interrupts so a two-byte
field is used. This structure is repeated for each separate interrupt required.
