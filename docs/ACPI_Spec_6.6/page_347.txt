5.2.32.5 Reset Reason Health Record
The Reset Reason Health Record defines a mechanism to describe the cause of the last system reset or boot. The record
will be created as a Health Record in the PHAT table. This provides a standard way for system firmware to inform the
operating system of the cause of the last reset. This includes both expected and unexpected events to support insights
across a fleet of systems by way of collecting the reset reason records on each boot.
The record provides an optional vendor reason to capture the underlying state used to generate the reset reason (e.g.
hardware registers) to support vendor specific details. The reset reason is intended to supplement existing fault reporting
mechanisms on the platform (e.g. BERT tables, CPER) or in the operating system (e.g. event logs)
