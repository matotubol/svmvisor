6.4.3.14 Clock Input Resource Descriptor
A Clock Input Resource Descriptor is used to describe the frequency and source device of a clock input supplied by
the platform to this Device. For a clock signal with a fixed frequency, a Clock Source entry is not required. If a Clock
Source is provided, control of the clock is managed by that Clock Source Device. The frequency of the input clock is
determined by Numerator and Divisor values along with a Scale value used for units. For example, a PCI clock could
be described by a numerator of 100, a divisor of 3, and a Scale of MHz.
