Chapter 3: Designing with the Core
To change the QSPI clock frequency in the Vivado Design Suite:
1.
Enable Dual Quad SPI configuration as shown in Figure 3-80.
a.
Select the Peripheral I/O Pins menu.
b.
Expand Quad SPI Flash settings.
c.
Select Dual Quad SPI (8bit).
2.
Modify the Quad SPI clock frequency as shown in Figure 3-81.
a.
Select the Clock Configuration menu.
b.
Expand IO Peripheral Clocks settings.
