cfg_pcie_link_state[2:0]
Output
PCI Express Link State: This encoded bus reports the PCI Express Link 
State information.
• 000: L0
• 001: PPM L1
• 010: PPM L2/L3 Ready
• 011: PM_PME
• 100: in or transitioning to/from ASPM L0s
• 101: transitioning to/from PPM L1
• 110: transition to PPM L2/L3 Ready
• 111: Reserved
cfg_trn_pending
Input
User Transaction Pending: If asserted, sets the Transactions Pending bit 
in the Device Status Register. 
Note: You must assert this input if the user application has not received a 
completion to an upstream request.
