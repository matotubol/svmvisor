Chapter 3: Designing with the Core
Tandem PCIe is similar to the standard model used today in terms of tool flow and bitstream 
generation. Two bitstreams are produced when running bitstream generation. One BIT file 
representing the stage 1 is downloaded into the PROM while the other BIT file representing 
the user application (stage 2) configures the remainder of the FPGA using the Internal 
Configuration Access Port (ICAP).
Note: Field updates of the stage 2 bitstream, that is, multiple user application images for an 
unchanging stage 1 bitstream, require Dynamic Function eXchange (DFX), which is not a supported 
flow for 7 series and Zynq devices. If this capability is required, a standard DFX flow, utilizing a black 
box configuration and compression, should be used.
