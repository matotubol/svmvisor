EVEX.b (Bit [4]). Specifies either broadcast of a memory read or to turn on the explicit rounding or
suppress all exceptions features as shown in Table 1-28.
EVEX.V' (Bit [3]). Used to specify an additional operand for three operand instructions. Encodes bit
[4] of a ZMM/YMM/XMM register in ones’ complement form. Bits [3:0] of the same register operand
are specified in EVEX.vvvv.
EVEX.aaa (Bits [2:0]). Specifies a K register to use for masking the result of an instruction when
EVEX.aaa != 000b. When EVEX.aaa == 000b, rather than using the value in K0, this specifies that K
masking is not occurring. This is similar to using a K mask register with all bits set.
