AMD64 Technology
Loads a cache line from the specified memory address into the data or instruction cache level specified
by the locality reference bits 5:3 of the ModRM byte. Table 3-3 on page 296 lists the locality reference
options for the instruction. 
This instruction loads a cache line even if the mem8 address is not aligned with the start of the line. If
the cache line is already contained in a cache level that is lower than the specified locality reference, or
if a memory fault is detected, a bus cycle is not initiated and the instruction is treated as a NOP.
The operation of this instruction is implementation-dependent. The processor implementation can
ignore or change this instruction. The size of the cache line also depends on the implementation, with a
minimum size of 32 bytes. Some AMD processors alias PREFETCHT1 and PREFETCHT2 to
PREFETCHT0. Also for PREFETCHIT0 and PREFETCHIT1, some processors may only prefetch if
the memory operand is a RIP-relative memory address. Support for PREFETCHIT0 and
PREFETCHIT1 is indicated by CPUID Fn8000_0021_EAX[PREFETCHI] = 1. For details on the use
of this instruction, see the software-optimization documentation relating to particular hardware
implementations.
