1.10
Encoding Using the EVEX Prefix
AVX512 introduces a new extended escape sequence called the EVEX prefix. It is a four byte
sequence. It is similar to the VEX prefix with additional register specifier bits and bits for enhanced
features.
Many (but not all) AVX512 instructions use the EVEX prefix. Instructions that are not AVX512 can
also use the EVEX prefix.
