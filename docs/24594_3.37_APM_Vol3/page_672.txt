E.3.13 Function 10h—PQOS Enforcement (PQE)
If PQE is supported (CPUID Fn0000_0007_EBX_x0[PQE] = 1), this CPUID function can be used to 
obtain PQE feature information. If PQE is not supported this function is reserved. For more 
information on using PQE, see “Platform Quality of Service” in APM Volume 2.
