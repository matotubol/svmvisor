2.5.10 INVALID_PPR_REQUEST Event
When supported, an INVALID_PPR_REQUEST event log entry is generated when the peripheral 
page request or the completion command has a problem (see Table 52). 
When Capability Offset 00h[EFRSup]=0 or MMIO Offset 0030h[PPRSup]=0, the PCIe page request 
interface (PRI) is not supported by an IOMMU implementation and a COMPLETE_PPR_REQUEST 
command will cause an ILLEGAL_COMMAND_ERROR event. When PRI is supported (MMIO 
Offset 0030h[PPRSup]=1), a PRI request from a peripheral is invalid when MMIO Offset 
0018h[PPREn]=0 or MMIO Offset 0018h[PPRLogEn]=0. An individual peripheral is not enabled for 
PRI when Capability Offset 0030h[EPHSup]=1 and DTE[PPR]=0.
