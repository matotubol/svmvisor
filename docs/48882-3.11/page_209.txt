31:27
MsiNumPPR: Peripheral Page Request MSI message number. RO. Reset X_XXXXb. This field must indicate 
which MSI/MSI-X vector is used for the interrupt message generated by the IOMMU for the peripheral page 
request log when MMIO Offset 0030h[PPRSup] = 1. MsiNumPPR must be zero when PPRSup = 0.
For MSI there can only be one IOMMU so this field must be zero (Section 3.1 “PCI Resources” on page 205).
For MSI-X, the value in this field indicates which MSI-X Table entry is used to generate the interrupt message.
Either MSI or MSI-X must be implemented, but not both. This interrupt is not remapped by the IOMMU. If 
neither MSI nor MSI-X are enabled and a PPR interrupt occurs, the interrupt is silently dropped.
Implementation Note: INTx is not supported for the PPR interrupt.
