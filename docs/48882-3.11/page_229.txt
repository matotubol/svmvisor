3.4.2 PPR Log Registers
This register specifies the system physical address and length of the peripheral page request log. 
Peripheral requests for page service handling are converted to entries in the PPR log.
This register is reserved when Capability Offset 00h[EFRSup] = 0b or when MMIO Offset 
0030h[PPRSup] = 0b. Page service requests detected by the IOMMU are reported in the event log 
(see Section 2.5.3 “IO_PAGE_FAULT Event” on page 152).
If PPRLogLen or PPRLogBase is changed while the PPRLogRun = 1, the IOMMU response is unde-
fined.
