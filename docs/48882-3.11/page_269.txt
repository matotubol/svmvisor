AMD I/O Virtualization Technology (IOMMU) Specification
48882-PUB—Rev 3.11—Apr 2026
Table 84: Architectural Counter Input Group, CAC = 0b
CSource
(decimal)
Architectural Counter Input Group Selection
0
No events. Note: CountUnits = 0 stops the counter and CountUnits = 1 is a free-run counter.
1
Peripheral memory operations passed-through: Total number of untranslated requests that did not undergo 
translation and were passed through IOMMU.
2
Peripheral memory operations passed-through: Total number of pre-translated requests passed through the 
IOMMU.
3
Peripheral memory operations passed-through: Number of requests targeting the Exclusion Range that were 
excluded from translation and access checks.
4
Peripheral memory operations target aborted.
5
Peripheral memory operations translated: Total number of requests that were translations of untranslated 
requests.
6
Peripheral memory operations translated: Total number of translations of untranslated requests that resulted 
in an IOMMU PTE TLB hit.
7
Peripheral memory operations translated: Total number of translations of untranslated requests that resulted 
in an IOMMU PTE TLB miss.
8
Peripheral memory operations translated: IOMMU TLB hit on PDE. 
This value is the sum of misses at all levels from level 6 down to level 1.
9
Peripheral memory operations translated: IOMMU TLB miss on PDE. 
This value is the sum of misses at all levels from level 6 down to level 1.
10
Peripheral memory operations: Number of DTE cache hits.
11
Peripheral memory operations: Number of DTE cache misses.
12
IOMMU page table read operations due to memory translation: Total.
This value is the addition of page table reads due to either host or guest page table walks. This excludes 
atomics.
13
IOMMU page table read operations due to memory translations for a host/nested walk.
Includes all host page levels. Atomics are excluded.
14
IOMMU page table read operations due to memory translations for a guest. 
Includes all guest page levels from PML5e to PTE. Atomics are excluded.
15
Peripheral interrupt operations: Interrupt request remapped (translated) with a DTE cache hit.
16
Peripheral interrupt operations: Interrupt request remapped (translated) with a DTE cache miss.
17
IOMMU commands processed: Total commands from the host command buffer.
18
IOMMU commands processed: Total invalidation commands only from the host command buffer.
19
IOMMU TLB invalidations processed from the host command buffer.
20
Unused
21
Peripheral interrupts for guest virtual APIC, IRTE[GuestMode] = 0b (see Figure 17 on page 95 and 
Table 22 on page 95).
22
Peripheral interrupts for guest virtual APIC, IRTE[GuestMode] = 1b (see Figure 18 on page 96 and 
Table 23 on page 96).
23
SMI interrupt requests received (see Section 2.1.5.2 “SMI Filter Address Format” on page 56).
24
SMI interrupt requests matched and blocked (see Section 2.1.5.1 “SMI Filter Operation” on page 55).
25-255
Reserved (treated as CSource = 0 and CountUnits = 0).
