5.3 I/O Virtualization Device Tree
The I/O Virtualization Device Tree (IVDT) is an alternative to the IVRS data structure described 
above. I/O device information should be supplied by platform firmware in the device tree format 
whenever ACPI-compatibility is not a requirement or not desirable (for instance, on an x86 platform 
built for Linux).
