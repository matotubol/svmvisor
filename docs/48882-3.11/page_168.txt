2.5.12 GUEST_EVENT_FAULT Event
When INSERT_GUEST_EVENT is supported, IOMMU generates a GUEST_EVENT_FAULT event 
when the reserved bits in the INSERT_GUEST_EVENT command are not zero.  GUEST_EVENT_-
FAULT event is always written in pairs with a guest event entry immediately after it into the event 
log, which takes up two event log entries.  The guest event entry is taken from the original guest event 
which pair with the INSERT_GUEST_EVENT.
