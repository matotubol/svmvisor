3.4.16Command and Event Status Register
This register indicates the current status of the IOMMU command and event processing. If interrupts 
are enabled, the IOMMU signals an interrupt when one of the interrupt status bits is set by hardware 
and no other interrupts status bits are set. Other bits report the status of command buffer processing 
and event logging.
