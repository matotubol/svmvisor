AMD I/O Virtualization Technology (IOMMU) Specification
The IOMMU Counter Register [MMIO Offset [40-7F][0-F]00h] is incremented when IOMMU 
PASID Match Register [MMIO Offset [40-7F][0-F]10h], IOMMU Domain Match Register [MMIO 
Offset [40-7F][0-F]18h], and IOMMU DeviceID Match Register [MMIO Offset [40-7F][0-F]20h] 
match or are ignored.
 
This register contains the PASID filter mask and the PASID for which to count events in the corre-
sponding counter register. The incoming PASID is ANDed with the PASIDMask field and the result 
is compared to the PASIDMatch field. If the comparison result is the same value, the event is enabled 
to be counted in the corresponding counter.

PASIDMatch. RW. Reset 0. This value is compared to the masked (filtered) value of the incoming PASID of 
the transaction to decide to count the corresponding event. The event is counted if PASIDMatch is equal to the 
masked incoming PASID; the event is not counted if they are not equal.
