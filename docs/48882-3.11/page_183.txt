If the PCIe PRI request has a PASID TLP prefix with a valid PASID, it is a GVA request and the 
header contains a PASID. If the PRI request packet lacks a PASID TLP prefix with a valid PASID, it 
is a nested (GPA) request and the PASID in the log entry must be ignored by software. The presence 
of a valid PASID is indicated to software by the GN bit in the log entry.
