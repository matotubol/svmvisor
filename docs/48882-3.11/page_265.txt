Description
63:0
DomainLock: Domain lock enable. RW. Reset 0. 0 = Corresponding counter bank of Domain-match registers is 
unlocked. 1 = locked (writes are ignored). For each bit in DomainLock, the corresponding Domain-match 
registers in an IOMMU counter bank may be changed. See IOMMU Domain Match Register [MMIO Offset 
[40-7F][0-F]18h]. Bit positions above the value reported in MMIO Offset 4000h[NCounterBanks] are ignored 
when written and return zero when read. The counter banks are numbered starting with zero; DomainLock[0] 
controls bank 0, DomainLock[1] controls bank 1, etc.
