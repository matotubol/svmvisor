AMD I/O Virtualization Technology (IOMMU) Specification
This register contains the DeviceID filter mask and the DeviceID for which to count events in the cor-
responding counter register. The incoming DeviceID is ANDed with the DeviceIDMask field and the 
result is compared to the DeviceIDMatch field. If the comparison result is the same value, the event is 
enabled to be counted in the corresponding counter.
