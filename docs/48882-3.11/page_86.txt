AMD I/O Virtualization Technology (IOMMU) Specification
Figure 11: Address Translation Example with Skipped Level and 2-Mbyte Page
The input address in Figure 11 is a GPA that is supplied by the peripheral or translated from a GVA. 
Using the nested page tables, the IOMMU translates the input GPA to an SPA within a 2-Mbyte phys-
ical page. The input address is mapped into page table offsets for the levels of address translation. The 
level-4 page table offset is used to index into the level-4 page table. The level-3 table offset is zero, so 
the contents of the level-4 page table entry points directly to a level-2 page table. The level-2 page 
table contains an entry with the next level=0, so that entry points directly to a 2-Mbyte page and the 
physical page offset is the 21 low-order bits of the input address.
