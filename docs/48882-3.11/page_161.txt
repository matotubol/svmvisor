INVALID_DEVICE_REQUEST Event
If the IOMMU receives a request from a device that the device is not allowed to perform, the 
IOMMU writes the event log with a INVALID_DEVICE_REQUEST event (see Table 50). Creation 
of event log entries for INVALID_DEVICE_REQUEST events is controlled by the IG bit in the 
Device Table entry (Figure 7 and Table 7). Depending on the type of the INVALID_DEVICE_RE-
QUEST (Table 64), some of the fields in Figure 62 and Table 65 will not be meaningful.
