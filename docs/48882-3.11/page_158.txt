ILLEGAL_COMMAND_ERROR Event
If the IOMMU reads an invalid command (including an unsupported command code, or a command 
that incorrectly has reserved bits set), the IOMMU writes the event log with an ILLEGAL_COM-
MAND_ERROR event (see Table 48). The IOMMU must stop fetching new commands from the 
command buffer if an ILLEGAL_COMMAND_ERROR event is detected.
