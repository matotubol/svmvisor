The base functionality of the IOMMU supports one-level translation tables for address translation and 
for interrupt remapping. The event log is the only data structure in system memory that is written by 
the IOMMU. The maximum size of a virtual address (GPA) is defined in Capability Offset 
10h[VAsize] and the maximum size of a physical address (SPA) is defined in Capability Offset 
10h[PAsize].
