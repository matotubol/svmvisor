AMD I/O Virtualization Technology (IOMMU) Specification
2.5.8
IOTLB_INV_TIMEOUT Event
If the IOMMU sends an invalidation request to a device and does not receive a response before the 
invalidation timeout timer expires, the IOMMU writes the event log with a IOTLB_INV_TIMEOUT 
event (see Table 49). See special considerations in Section 2.1.4.13.
The Address field contains the system physical address of the invalidation command that timed out.
