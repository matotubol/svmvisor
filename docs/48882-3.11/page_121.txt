2.3.2
Making Guest Interrupt Virtualization Changes
Software may change the guest interrupt virtualization information in the IRTE in the following man-
ner, according to the value of RemapEn before the change in the relevant IRTE. 
•
If RemapEn=0 before the change, changes can be made in any order as long as the last change is 
to set RemapEn=1.
•
If RemapEn=1 before the change, the following steps may be followed to change interrupt 
virtualization information:
•
Atomically update the IRTE.
•
If any cacheable fields of the IRTE were modified, invalidate the interrupt remapping table. 
See Section 2.2.5.2 “Interrupt Virtualization Tables with Guest Virtual APIC Enabled” on 
page 92 and Section 2.4.5 “INVALIDATE_INTERRUPT_TABLE” on page 131.
