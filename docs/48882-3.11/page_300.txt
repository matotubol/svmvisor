AMD I/O Virtualization Technology (IOMMU) Specification
Mixed Format IVHD Block
Mixed format IVHD blocks can contain fixed-length assigned DeviceID device entries and variable 
length ACPI HID named device entries. The mixed format IVHD block is identified as Type = 40h. If 
IVinfo[EFRSup] = 0, IVHD Type 40h is Reserved.
