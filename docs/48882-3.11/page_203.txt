2.14 SEV-TIO: Trusted I/O for Secure Encrypted Virtualization 
SEV-TIO is a key component of AMD's Trusted I/O architecture with the goal to enable I/O devices 
to operate with Trusted Virtual Machines (TVMs) in a confidential compute environment. SEV-TIO 
allows SEV-SNP guest to establish trust in a device that supports TEE Device Interface Security 
Protocol (TDISP), as defined by PCI-SIG, and then interacts with the device via private memory. A 
TDISP device consists of one or more TEE Device Interfaces (TDIs) that can be securely assigned to 
SNP guest.
2.14.1 Non-Secure Device Table
In SEV-TIO mode, security-sensitive fields (such as domainID, sATS, GCR3, Guest Page Mode, and 
GLX) are moved from device table entry (DTE) to a secure data structure maintained by ASP. These 
fields are programmed by ASP based on the input from host and guest, as explained in SEV-TIO 
Firmware Interface Specification, order #58271. For TDIs, the IOMMU processes incoming requests 
such as DMA, Interrupts, and PRIs by utilizing both the non-secure DTE and the ASP-owned secure 
data structure.
