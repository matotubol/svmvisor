3.4.22IOMMU Event Counter Registers
If IOMMU Extended Feature Register [MMIO Offset 0030h][PCSup] = 0, the event counter registers 
are reserved.
3.4.22.1 MMIO Event Counter Control Registers
The following set of registers, MMIO Offset 4000h through MMIO Offset 4018h, control the 
IOMMU event counters. 
This register reports the type and number of counters available to software.
