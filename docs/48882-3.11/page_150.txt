ILLEGAL_DEV_TABLE_ENTRY Event
When the IOMMU performs a lookup in the Device Table and encounters a Device Table entry that it 
does not support or that is formatted incorrectly, the IOMMU writes an ILLE-
GAL_DEV_TABLE_ENTRY event to the event log as listed in Table 43.
