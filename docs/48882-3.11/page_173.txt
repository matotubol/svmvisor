2.5.15 RMP_HARDWARE_ERROR Event
In an SNP-enabled system, if the IOMMU detects a hardware error (master abort, target abort, poi-
soned data, etc.) while accessing the RMP entries, it must fault the translation request and log an 
RMP_HARDWARE_ERROR event. See Figure 70.
