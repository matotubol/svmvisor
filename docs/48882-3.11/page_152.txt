AMD I/O Virtualization Technology (IOMMU) Specification
2.5.3
IO_PAGE_FAULT Event
When the IOMMU performs a lookup in the page tables for a device and encounters an error condi-
tion in Table 44, the IOMMU writes the event log with an IO_PAGE_FAULT event as controlled by 
the SA, SE, IG, and SupIOPF bits (see Figure 7 and Table 7 or Figure 15 and Table 10).
When supported, IO_PAGE_FAULT events generated by the SMI filter (see Section 1.3.10) are 
reported with Address[63:0] containing the upstream SMI request address. The MMIO Offset 
0018h[SmiFLogEn] bit controls the logging of IO_PAGE_FAULT events reported by the SMI filter; 
the SA, SE, IG, and SupIOPF bits do not affect SMI filter logging.
I/O page faults detected for translation requests return a translation-not-present response (R=W=0) to 
the device and are not logged in the event log.
