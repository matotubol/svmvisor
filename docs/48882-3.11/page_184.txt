AMD I/O Virtualization Technology (IOMMU) Specification
The log entry is designed to carry a full set of independent read-, write-, and execute-permission bits; 
any bits not provided by the underlying peripheral protocol are set to the “permitted” state by the 
IOMMU (see also MMIO Offset 0030h[NXSup]).
2.6.4
PPR Log Overflow Protection
The architecture provides a number of optional features that drastically reduce the likelihood of a 
PPR Log overflow. These features are:
•
PPR Auto Response
•
PPR Log Dual Buffering
•
PPR Auto Response Always-on
•
PPR Log Overflow Early Warning
•
Block StopMark Messages
