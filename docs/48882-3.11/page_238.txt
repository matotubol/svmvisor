AMD I/O Virtualization Technology (IOMMU) Specification
3.4.7 Device-Specific Feature Registers
The Device-Specific Feature Registers are used to report IOMMU hardware revision level informa-
tion to system software. Three registers are defined: the Device-Specific Feature Extension Register, 
the Device-Specific Control Extension Register, and the Device-Specific Status Extension Register.
