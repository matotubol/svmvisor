Software Note: Using the information contained in a Type 10h IVHD an indication of support for the 
performance counter feature can be derived from the IOMMU Feature Reporting Fields PNBanks 
and PNCounters. When PNBanks and PNCounters both equal 0, then the performance counter fea-
ture is not supported. (see MMIO Offset 0030h[PCSup]). The Type 11h IVHD (see the next section) 
supplies a direct indication of support for the performance counter feature by providing an image of 
the IOMMU Extended Feature Register [MMIO Offset 0030h] hardware register.
