Enhanced INVALID_DEVICE_REQUEST Event
This event is logged when a request is received from a device associated with a fenced Guest. For 
more details, refer to the SEV TIO Firmware Interface Specification, order #58271.
Note: If Type[3] is 0, the IOMMU logs the legacy Invalid_Device_Request event, as described in the 
IOMMU Specification, Section 2.5.9 “INVALID_DEVICE_REQUEST Event” on page 161.
