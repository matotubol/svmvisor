There must be at least one IVHD device entry to describe at least one I/O device or slot governed by 
the IOMMU; an IOMMU may govern multiple ranges and singletons of I/O devices. A IVHD device 
entry can provide information about a single device, a sub-range of devices, or all the devices virtual-
ized by that IOMMU. When a IVHD device entry defines the start of a range, a second device entry, 
immediately following the first, defines the end of the range. The range definition is inclusive of the 
first and last device specified. IVHD device entries specify the settings for specific IOMMU DTE 
fields for that device or range of devices in the IOMMU Device Table.
See “IVHD Device Entries” on page 302 for more information on device entries.
For peripherals that use source identification other than their own DeviceID, alias entries must be 
used. An IOMMU and the peripherals it serves must be on the same PCI Segment Group defined in 
the IVHD block. The IVHD length field specifies the number of bytes in the IVHD block, starting 
from the Type field.
There are two types of fixed-length IVHDs defined: Type 10h and Type 11h. Table 90, Table 91, 
Table 92, Table 93, Table 94, and Figure 91 define the Type 10h IVHD and Table 95, Table 96, 
Table 97, and Table 98 define the Type 11h IVHD.
