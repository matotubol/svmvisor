III-6.7.1.3 Error Code Definitions
Summary
Error code definitions for the Computing Unit class and all subclasses. See Error Code Operations in Computing
Unit Class for descriptions of these error codes.
The following subclasses define additional subclass-specific error code operations, which are included below:
• Host processor
• Firmware processor
• Cache
• Memory
