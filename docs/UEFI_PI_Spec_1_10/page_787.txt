Description
This function performs the equivalent operation as the Io.Write() function in the CPU I/O PPI. If this function
is called in virtual mode before any required mapping have been converted to virtual addresses, then EFI_
SAL_VIRTUAL_ADDRESS_ERROR is returned. Otherwise, the status from performing the Io.Write() function of
the CPU I/O PPI is returned.
