I-10.3.4 PEI Reset2 PPI
I-10.3.4.1 EFI_PEI_RESET2_PPI (Optional)
Summary
This PPI is installed by some platform- or chipset-specific PEIM that abstracts the ability to reset the platform.
GUID
#define EFI_PEI_RESET2_PPI_GUID \
{0x6cc45765, 0xcce4, 0x42fd, \

Parameters
ResetSystem
A service to reset the platform.
Description
These services provide a simple reset service. This is equivalent to the ResetSystem() API call in the UEFI2.4
specification.
