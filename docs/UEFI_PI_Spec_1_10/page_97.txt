I-9.7.1.1.1 PUSH
Syntax
PUSH <PPI GUID>
Description
Pushes a Boolean value onto the stack. If the GUID is present in the handle database, then a TRUE is pushed
onto the stack. If the GUID is not present in the handle database, then a FALSE is pushed onto the stack. The
test for the GUID in the handle database may be performed with the Boot Service LocatePpi() .
Operation
Status = (*PeiServices)->LocatePpi (PeiServices, GUID, 0, NULL, &Interface);
if (EFI_ERROR (Status)) {
PUSH FALSE;
} Else {
PUSH TRUE;
}

I-9.7.1.1.2 AND
Syntax
AND
Description
Pops two Boolean operands off the stack, performs a Boolean AND operation between the two operands, and
pushes the result back onto the stack.
Operation
Operand1 <= POP Boolean stack element
Operand2 <= POP Boolean stack element
Result <= Operand1 AND Operand2
PUSH Result
AND Instruction Encoding defines the AND instruction encoding.
