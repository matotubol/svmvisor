III-6.4.2.4.3 Keyboard Subclass
This subclass applies to any keyboard style interfaces. ExtendedData contains the device path to the keyboard
device as defined in EFI_DEVICE_PATH_EXTENDED_DATA and the instance is ignored.
See Subclass Definitions for the definition of this subclass.
