II-13.4.4 EFI_MP_SERVICES_PROTOCOL.StartupAllAPs()
Summary
This service executes a caller provided function on all enabled APs. APs can run either simultaneously or
one at a time in sequence. This service supports both blocking and non-blocking requests. The non-blocking
requests use EFI events so the BSP can detect when the APs have finished. See “Non-blocking Execution
Support” below for details. This service may only be called from the BSP.
