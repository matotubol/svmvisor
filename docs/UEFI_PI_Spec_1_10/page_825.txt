Parameters
FunctionId
Must be EsalFvbReadFunctionId .
Arg2
This argument is interpreted as type UINTN that represents the Firmware Volume Block instance. This
instance value is used to lookup a EFI_FIRMWARE_VOLUME_BLOCK_PROTOCOL . See the This parameter
in Related Definitions.
Arg3
This argument is interpreted as type EFI_LBA . See the Lba parameter in Related Definitions.
Arg4
This argument is interpreted as type UINTN . See the Offset parameter in Related Definitions.
Arg5
This argument is interpreted as a pointer to type UINTN . See the NumBytes parameter in Related
Definitions.
Arg6
This argument is interpreted as pointer to a buffer of type VOID * . See the Buffer parameter in Related
Definitions.
Arg7
Reserved. Must be zero.
Arg8
Reserved. Must be zero.
VirtualMode
TRUE if the Extended SAL Procedure is being invoked in virtual mode. FALSE if the Extended SAL
Procedure is being invoked in physical mode.
ModuleGlobal
A pointer to the global context associated with this Extended SAL Procedure. Implementation dependent.
