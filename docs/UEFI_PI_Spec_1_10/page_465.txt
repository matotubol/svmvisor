InformationType
The type identifier for the information being requested. Type EFI_GUID is defined in the UEFI 2.0

BufferSize
On input, the size of Buffer. On output, the amount of data returned in Buffer . In both cases, the size
is measured in bytes.
Buffer
A pointer to the data buffer to return. The buffer’s type is indicated by InformationType.
Description
The GetInfo() function returns information of type InformationType for the requested firmware volume. If
the volume does not support the requested information type, then EFI_UNSUPPORTED is returned. If the buffer
is not large enough to hold the requested structure, EFI_BUFFER_TOO_SMALL is returned and the BufferSize is
set to the size of buffer that is required to make the request. The information types defined by this specification
are required information types that all file systems must support.
