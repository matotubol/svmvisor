I-17.5.1 Self-Test State Parameter
Self-test state parameters are defined in the same format for IA-32 Intel® processors and the Intel® Itanium®
processor family. Some of the test status bits may not be relevant to IA-32 processors. In that case, these bits
will read NULL on IA-32 processors.
Self-Test State Bit Values indicates the meanings for various values of the self-test State parameter (bits 0:1) of
the Health flag.
