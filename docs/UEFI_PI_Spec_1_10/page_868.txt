Description
This function registers MCA state buffer specified by Agr3 for CPU specified by Arg2 . If the CPU specified by
Arg2 was not registered in system, then EFI_SAL_NO_INFORMATION is returned. Otherwise, the CPU state
buffer is registered for MCA handing, and EFI_SAL_SUCCESS is returned.
Status Codes Returned
EFI_SAL_SUCCESS
The CPU state buffer is registered for MCA handing successfully
EFI_SAL_NO_INFORMATION
The CPU was not registered in system
