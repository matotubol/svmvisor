Description
This function records the PAL Entry Point specified by Arg3 , so PAL_PROC calls can be made with the
EsalPalProcFunctionId Function ID. If Arg2 is TRUE , then Arg3 is the physical address of the PAL Entry Point. If
Arg2 is FALSE , then Arg3 is the virtual address of the PAL Entry Point. If this function is called in virtual mode
before any required mapping have been converted to virtual addresses, then EFI_SAL_VIRTUAL_ADDRESS_
ERROR is returned. Otherwise, the EFI_SAL_SUCCESS is returned.
