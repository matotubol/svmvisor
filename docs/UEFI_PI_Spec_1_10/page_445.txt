III-3.3.4 PEI Load File PPI
III-3.3.4.1 EFI_PEI_LOAD_FILE_PPI
Summary
Installed by a PEIM that supports the Load File PPI.
GUID
#define EFI_PEI_LOAD_FILE_PPI_GUID \
{ 0xb9e0abfe, 0x5979, 0x4914, \
0x97, 0x7f, 0x6d, 0xee, 0x78, 0xc2, 0x78, 0xa6 }
Prototype
typedef struct _EFI_PEI_LOAD_FILE_PPI {
EFI_PEI_LOAD_FILE
LoadFile;
} EFI_PEI_LOAD_FILE_PPI;
Parameters
LoadFile
Loads a PEIM into memory for subsequent execution. See the LoadFile() function description.
Description
This PPI is a pointer to the Load File service. This service will be published by a PEIM. The PEI Foundation
will use this service to launch the known PEI module images.
