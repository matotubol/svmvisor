II-7.2.4.7 SetMemorySpaceCapabilities()
Summary
This service modifies the capabilities for a memory region in the global coherency domain of the processor.
Prototype
typedef
EFI_STATUS
(EFIAPI *EFI_SET_MEMORY_SPACE_CAPABILITIES) (
IN EFI_PHYSICAL_ADDRESS
BaseAddress,
IN UINT64
Length,
IN UINT64
Capabilities*
);
Parameters
BaseAddress
The physical address that is the start address of a memory region. Type EFI_PHYSICAL_ADDRESS is
defined in the AllocatePages() function description in the UEFI Specification.
Length
The size in bytes of the memory region.
Capabilities
The bit mask of capabilities that the memory region supports. The bit mask of available attributes is
defined in the GetMemoryMap() function description in the UEFI specification.
