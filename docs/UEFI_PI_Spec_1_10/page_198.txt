I-12.4 Graphics PEIM Interfaces
There is one PEI to PEI Interfaces (PPI) that is required to provide graphics functionality in the PEI phase.
The PeiGraphicsPpi is the PPI produced by the Graphics PEI Module and provides interfaces to the platform
code to complete the basic initialization of the graphics subsystem to enable console output.
I-12.4.1 Pei Graphics PPI
The PeiGraphicsPpi is the main interface exposed by the Graphics PEIM to be used by the other firmware
modules.
The following sections cover the individual APIs in detail.
