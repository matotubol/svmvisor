III-6.4.2.4.14 Network Device Subclass
This subclass applies to network adapters attached to the system. These devices are capable of producing
standard UEFI networking protocols such as the EFI_SIMPLE_NETWORK Protocol.
See Subclass Definitions for the definition of this subclass.

III-6.4.3 I/O Bus Class
The I/O bus class covers hardware buses irrespective of any software protocols that are used. At a broad level,
everything that connects the computing unit to the user peripheral can be covered by this class. Subclass
elements correspond to industry-standard hardware buses. See the following for the I/O Bus class:
• instance number
• progress code operations
• error code operations
• defined subclasses
