Parameters
FunctionId
Must be EsalAddCpuDataFunctionId .
Arg2
The 64-bit Global ID of the CPU being added.
Arg3
The enable flag for the CPU being added. This value is interpreted as type BOOLEAN . TRUE means the
CPU is enabled. FALSE means the CPU is disabled.
Arg4
The PAL Compatibility value for the CPU being added.
Arg5
The 16-bit Platform ID of the CPU being added.
Arg6
Reserved. Must be zero.
Arg7
Reserved. Must be zero.
Arg8
Reserved. Must be zero.
VirtualMode
TRUE if the Extended SAL Procedure is being invoked in virtual mode. FALSE if the Extended SAL
Procedure is being invoked in physical mode.
ModuleGlobal
A pointer to the global context associated with this Extended SAL Procedure. Implementation dependent.
