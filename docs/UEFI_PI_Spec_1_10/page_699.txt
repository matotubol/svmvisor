IV-4.8.9 EFI_MM_MP_PROTOCOL.WaitForProcedure()
Summary
When a non-blocking execution of a procedure on an AP is invoked via DispatchProcedure , this function will
block the caller until the remote procedure has completed on the designated AP. The non-blocking procedure
invocation is identified by the Token parameter, which must match the token that used when DispatchProcedure
was called.
When a non-blocking execution of a procedure on an AP is invoked via BroadcastProcedure this function will
block the caller until the remote procedure has completed on all of the APs that entered MM. The non-blocking
procedure invocation is identified by the Token parameter, which must match the token that used when
BroadcastProcedure was called.
