ModuleGlobal
A pointer to the global context associated with this Extended SAL Procedure. Implementation dependent.
Description
This function returns a memory buffer to store error records. The base address of the buffer is returned in
SAL_RETURN_REGS .r9 , and the size of the buffer, in bytes, is returned in SAL_RETURN_REGS .r10 . If a
buffer is not available, then EFI_OUT_OF_RESOURCES is returned. Otherwise, EFI_SUCCESS is returned.
