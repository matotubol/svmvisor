I-13.4 HandoffProcessor State to the DXE IPL PPI
Handoff Processor State to the DXE IPL PPI defines the state that processors must be in at handoff to the DXE
IPL PPI, for the following processors:
• IA-32 processors
• Itanium processor family
• Intel ® processors using Intel ® XScaleTMtechnology
