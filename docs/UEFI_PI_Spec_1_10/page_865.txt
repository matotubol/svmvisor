Description
This function looks up the Physical ID of the calling CPU. If the calling CPU is not present in the database,
then EFI_SAL_NO_INFORMATION is returned. Otherwise, the Physical ID is returned in SAL_RETURN_REGS .
r9 , and EFI_SAL_SUCCESS is returned.
Status Codes Returned
EFI_SAL_SUCCESS
The Physical ID for the calling CPU was returned.
EFI_SAL_NO_INFORMATION
The calling CPU is not in the database.
