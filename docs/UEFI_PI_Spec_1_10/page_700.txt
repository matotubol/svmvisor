Members
RegisterMmFoundationEntry
A function to register the MM Foundation entry point.
Description
This Protocol is an MM Protocol published by a standalone MM CPU driver to allow MM Foundation register
MM Foundation entry point. If a platform chooses to let MM Foundation load standalone MM CPU driver for
MM relocation, this protocol must be produced this standalone MM CPU driver. The RegisterMmFoundationEn-
try() function allows the MM Foundation to register the MM Foundation entry point with the MM entry vector
code.
