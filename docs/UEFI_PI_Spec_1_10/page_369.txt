II-13.4.5 EFI_MP_SERVICES_PROTOCOL.StartupThisAP()
Summary
This service lets the caller get one enabled AP to execute a caller-provided function. The caller can request the
BSP to either wait for the completion of the AP or just proceed with the next task by using the EFI event mech-
anism. See the “Non-blocking Execution Support” section in EFI_MP_SERVICES_PROTOCOL.StartupAllAPs()
for more details. This service may only be called from the BSP.
