Description
This function performs the equivalent operation as the ReportStatusCode function of the Status Code Runtime
Protocol. If this function is called in virtual mode before any required mapping have been converted to virtual
addresses, then EFI_SAL_VIRTUAL_ADDRESS_ERROR is returned. Otherwise, the one of the status codes
defined in the ReportStatusCode() function of the Status Code Runtime Protocol is returned.
