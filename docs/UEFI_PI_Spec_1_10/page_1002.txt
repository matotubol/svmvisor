V-10.8.4 EFI_PCI_HOST_BRIDGE_RESOURCE_ALLOCATION_PROTOCOL.NotifyPhase()
Summary
These are the notifications from the PCI bus driver that it is about to enter a certain phase of the PCI
enumeration process.
Prototype
typedef
EFI_STATUS
(EFIAPI
*EFI_PCI_HOST_BRIDGE_RESOURCE_ALLOCATION_PROTOCOL_NOTIFY_PHASE)

Phase
);
Parameters
This
Pointer to the EFI_PCI_HOST_BRIDGE_RESOURCE_ALLOCATION_PROTOCOL instance.
Phase
The phase during enumeration. Type EFI_PCI_HOST_BRIDGE_RESOURCE_ALLOCATION_PHASE is
defined in “Related Definitions” below.
Description
This member function can be used to notify the host bridge driver to perform specific actions, including any
chipset-specific initialization, so that the chipset is ready to enter the next phase. Nine notification points are
defined at this time. See “Related Definitions” below for definitions of various notification points and Sample
Implementation for usage.
