III-6.4.2.4.10 Removable Media Subclass
This subclass applies to removable media peripherals such as floppy disk drives or LS-120 drives. These
peripherals are capable of producing the EFI_BLOCK_IO Protocol. ExtendedData contains the device path to
the device as defined in EFI_DEVICE_PATH_EXTENDED_DATA and the instance is ignored.
See Subclass Definitions for the definition of this subclass.
