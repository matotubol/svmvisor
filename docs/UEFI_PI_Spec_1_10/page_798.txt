UEFI Platform Initialization Specification, Release 1.10
IV-11.4.6 ExtendedSalSetWakeupTime
Summary
This function is equivalent in functionality to the EFI Runtime Service SetWakeupTime() . See UEFI 2.0
Specification Section 7.2. The function prototype for the SetWakeupTime() service is shown in Related
Definitions.
