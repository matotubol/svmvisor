III-8.2.1.15 EFI_PEI_PCD_PPI.CallbackOnSet ()
Summary
Specifies a function to be called anytime the value of a designated token is changed.

Parameters

The 128-bit unique value that designates which namespace to monitor. If NULL , use the standard
platform namespace.
CallBackToken
The PCD token number to monitor.
CallBackFunction
The function prototype that will be called when the value associated with the CallBackToken is set.
