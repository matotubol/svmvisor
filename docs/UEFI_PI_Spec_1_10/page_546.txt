III-6.5.6 Runtime (RT) Subclass
This subclass applies to runtime software. Runtime software is made up of the UEFI-aware operating system
and the non-UEFI software running under the operating system environment. Other firmware components,
such as SAL code or ASL code, are also executing during this phase but cannot call a UEFI runtime service.
Hence no codes are reserved for them.
