V-17.3.9 I2C I/O PPI
V-17.3.10 EFI_PEI_I2C_IO
Summary
The EFI I2C I/O PPI enables the user to manipulate a single I2C device independent of the host controller and
I2C bus design.
GUID
#define EFI_PEI_I2C_IO_GUID \
{ 0x42179ed0, 0x2fa2, 0x47c0, 0x85, 0x7e, 0x8b, 0xc0, \
0x18, 0x81, 0xea, 0x97 }
PEIM-to-PEIM Interface Structure
typedef struct {
EFI_PEI_I2C_IO_GET_DEVICE_INFO
GetDeviceInfo;
EFI_PEI_I2C_IO_GET_DEVICE_INFO_ID_LIST
GetDeviceInfoIdList;
EFI_PEI_I2C_IO_START_REQUEST
StartRequest;
EFI_I2C_DEVICE
*I2cDevice;
CONST EFI_I2C_CONTROLLER_CAPABILITIES
*I2cControllerCapabilities;
} EFI_PEI_I2C_IO;
Parameters
GetDeviceInfo
Get a blob of data identified by a GUID.
GetDeviceInfoIdList
Get a list of the GUIDs associated with this I2C device.
StartRequest
Start a transaction on the I2C device.
I2cDevice
A pointer to the EFI_I2C_DEVICE structure contained within the I2C platform driver.
