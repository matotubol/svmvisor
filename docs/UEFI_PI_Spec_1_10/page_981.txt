V-9.1.8 EFI_ACPI_SDT_PROTOCOL.SetOption()
Summary
Change information about an ACPI object.
Prototype
typedef
EFI_STATUS
(EFIAPI \*EFI_ACPI_SET_OPTION) (
IN EFI_ACPI_HANDLE
Handle,
IN UINTN
Index,
IN CONST VOID
*Data,
IN UINTN
DataSize
);
Parameters
Handle
ACPI object handle.
Index
Index of the data to retrieve from the object. In general, indexes read from left-to-right in the ACPI
encoding, with index 0 always being the ACPI opcode.
Data
Points to the data.
DataSize
The size of the Data .
