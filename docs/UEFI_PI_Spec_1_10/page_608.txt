REPORT STATUS CODE ROUTERS
III-7.1 Overview
This section provides the code definitions for the PPI and Protocols used in a Report Status Code Router. These
interfaces allow multiple platform dependent drivers for displaying status code information to coexist without
prior knowledge of one another.
Fig. 7.1: Status Code Services
There is a generic status code driver in each phase. In each case the driver consumes the Report Status Code
Protocol and produces the Report Status Code Handler PPI or Protocol. Each consumer of the Report Status
Code Handler PPI or Protocol will register a callback to receive notification of new Status Codes from the
Generic Status Code Driver.
