II-10.7.1 BEFORE
Syntax
BEFORE <File Name GUID>
Description
This opcode tells the DXE Dispatcher that the DXE driver that is associated with this dependency expression
must be dispatched just before the DXE driver with the file name specified by GUID . This means that as soon
as the dependency expression for the DXE driver specified by GUID evaluates to TRUE , then this DXE driver
must be placed in the dispatch queue just before the DXE driver with the file name specified by GUID .
Operation
None.

Behaviors and Restrictions
If this opcode is present in a dependency expression, it must be the first and only opcode in the expression. If
is appears in any other location in the dependency expression, then the dependency expression is evaluated
to FALSE .
