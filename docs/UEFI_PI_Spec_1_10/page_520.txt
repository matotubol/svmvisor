III-6.4.2.4.6 Remote Console Subclass
This subclass applies to any console not directly connected to the system. This would include consoles
displayed via serial or LAN Hconnections. ExtendedData contains the device path to the console device as
defined in EFI_DEVICE_PATH_EXTENDED_DATA and the instance is ignored.
See Subclass Definitions for the definition of this subclass.

III-6.4.2.4.7 Serial Port Subclass
This subclass applies to devices attached to a system serial port, such as a modem. ExtendedData contains the
device path to the device as defined in EFI_DEVICE_PATH_EXTENDED_DATA and the instance is ignored.
See Subclass Definitions for the definition of this subclass.
