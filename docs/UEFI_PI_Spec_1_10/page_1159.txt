V-19.1 Error Code Definitions
For 32-bit architecture:
#define EFI_INTERRUPT_PENDING
0xa0000000
#define EFI_WARN_INTERRUPT_SOURCE_PENDING
0x20000000
#define EFI_WARN_INTERRUPT_SOURCE_QUIESCED
0x20000001
For 64-bit architecture:
#define EFI_INTERRUPT_PENDING
0xa000000000000000
#define EFI_WARN_INTERRUPT_SOURCE_PENDING
0x2000000000000000
#define EFI_WARN_INTERRUPT_SOURCE_QUIESCED
0x2000000000000001
