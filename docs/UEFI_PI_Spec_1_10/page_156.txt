BufferSize
The size of the Buffer in bytes. This number must be a multiple of the intrinsic block size of the device.
Buffer
A pointer to the destination buffer for the data. The caller is responsible for the ownership of the buffer.
Description
The function reads the requested number of blocks from the device. All the blocks are read, or an error is
returned. If there is no media in the device, the function returns EFI_NO_MEDIA.

Status Codes Returned
EFI_SUCCESS
The data was read correctly from the device
EFI_DEVICE_ERROR
The device reported an error while attempting to perform the
read operation
EFI_INVALID_PARAMETER
The read request contains LBAs that are not valid or the buffer
is not properly aligned
EFI_NO_MEDIA
There is no media in the device
EFI_BAD_BUFFER_SIZE
The BufferSize parameter is not a multiple of the intrinsic
block size of the device
