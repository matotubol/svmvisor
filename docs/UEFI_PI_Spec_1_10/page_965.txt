Parameters
This
A pointer to the EFI_S3_SAVE_STATE_PROTOCOL instance.
OpCode
Must be set to EFI_BOOT_SCRIPT_STALL_OPCODE . Value EFI_BOOT_SCRIPT_STALL_OPCODE is defined
in “Related Definitions” in EFI_S3_SAVE_STATE_PROTOCOL.Write() .
Duration
Duration in microseconds of the stall.
Description
This function adds a stall record into a specified boot script table. When the script is executed, this operation
will stall the system for Duration number of microseconds.
Status Codes Returned
See “Status Codes Returned” in Write() .
