SMBUS PPI CODE DEFINITIONS
V-5.1 Introduction
This section contains the basic definitions for PEIMs and SMBus devices to use during the PEI phase. The
following PPI is defined in this section:
• EFI_PEI_SMBUS2_PPI
This section also contains the definitions for additional SMBus-related data types and structures that are
subordinate to the structures in which they are called. All of the data structures below except for EFI_PEI_
SMBUS_NOTIFY_FUNCTION can be used in the DXE phase as well. The following types or structures can be
found in “Related Definitions” of the parent function definition:
• EFI_SMBUS_DEVICE_ADDRESS
• EFI_SMBUS_DEVICE_COMMAND
• EFI_SMBUS_OPERATION
• EFI_SMBUS_UDID
• EFI_SMBUS_DEVICE_MAP
• EFI_PEI_SMBUS_NOTIFY_FUNCTION
V-5.2 PEI SMBus PPI
V-5.2.1 EFI_PEI_SMBUS2_PPI
Summary
Provides the basic I/O interfaces that a PEIM uses to access its SMBus controller and the slave devices attached
to it.
GUID
#define EFI_PEI_SMBUS2_PPI_GUID \\
{ 0x9ca93627, 0xb65b, 0x4324, \\
0xa2, 0x2, 0xc0, 0xb4, 0x61, 0x76, 0x45, 0x43 }
PPI Interface Structure
typedef struct _EFI_PEI_SMBUS2_PPI {
EFI_PEI_SMBUS2_PPI_EXECUTE_OPERATION Execute;
EFI_PEI_SMBUS2_PPI_ARP_DEVICE ArpDevice;
EFI_PEI_SMBUS2_PPI_GET_ARP_MAP GetArpMap;
