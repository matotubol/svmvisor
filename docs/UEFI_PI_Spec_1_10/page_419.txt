#define EFI_FV_EXT_TYPE_OEM_TYPE 0x01
typedef struct {
EFI_FIRMWARE_VOLUME_EXT_ENTRY
Hdr;
UINT32

//EFI_GUID
Types[];
} EFI_FIRMWARE_VOLUME_EXT_ENTRY_OEM_TYPE;
Hdr
Standard extension entry, with the type EFI_FV_EXT_TYPE_OEM_TYPE .
TypeMask
A bit mask, one bit for each file type between 0xC0 (bit 0) and 0xDF (bit 31). If a bit is ‘1’, then the
GUID entry exists in Types . If a bit is ‘0’ then no GUID entry exists in Types . For example, the value
0x01010301 would indicate that there would be five total entries in Types for file types 0xC0 (bit 0),
0xC8 (bit 4), 0xC9 (bit 5), 0xD0 (bit 16), and 0xD8 (bit 24).
Types
An array of GUIDs, each GUID representing an OEM file type.
This extension header provides a mapping between a GUID and an OEM file type.
