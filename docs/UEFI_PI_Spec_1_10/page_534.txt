III-6.5 Software Classes
III-6.5.1 Host Software Class
The Host Software class covers any software-generated codes. Subclass elements correspond to common
software types in a PI Architecture system. See the following for the Host Software class:
• instance number
• progress code operations
• error code operations
• defined subclasses
III-6.5.2 Instance Number
The instance number is not used for software subclasses unless otherwise stated.
