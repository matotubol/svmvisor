Protocol Interface Structure
typedef struct {
EFI_RSC_HANDLER_REGISTER
Register;
EFI_RSC_HANDLER_UNREGISTER
Unregister;
} EFI_RSC_HANDLER_PROTOCOL;
Members
Register
Register the callback for notification of status code messages.
Unregister
Unregister the callback.
Description
Once registered, status code messages will be forwarded to the callback. The callback must be unregistered
before it is deallocated.
