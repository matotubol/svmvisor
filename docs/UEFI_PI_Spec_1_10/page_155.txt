Parameters
PeiServices
General-purpose services that are available to every PEIM. Type EFI_PEI_SERVICES is defined in (EFI_
PEI_SERVICES) .
This
Indicates the EFI_PEI_RECOVERY_BLOCK_IO_PPI instance.
DeviceIndex
Specifies the block device to which the function wants to talk. Because the driver that implements Block
I/O PPIs will manage multiple block devices, the PPIs that want to talk to a single device must specify
the device index that was assigned during the enumeration process. This index is a number from one to
NumberBlockDevices .
StartLBA
The starting logical block address (LBA) to read from on the device. Type EFI_PEI_LBA is defined in
