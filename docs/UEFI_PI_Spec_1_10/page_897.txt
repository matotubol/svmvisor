Data

NotifyFunction
The function to call when the bus driver detects the SlaveAddress and Data pair. Type EFI_SMBUS_
NOTIFY_FUNCTION is defined in “Related Definitions” below.
Description
The Notify() function registers all the callback functions to allow the bus driver to call these functions when
the SlaveAddress / Data pair happens.
