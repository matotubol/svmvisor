Description
This function sets the MINSTATE pointer for the CPU specified by Arg2 to the buffer specified by Arg3 . If the
CPU specified by Arg2 is not present in the database, then EFI_SAL_NO_INFORMATION is returned. Otherwise,
EFI_SAL_SUCCESS is returned.
Status Codes Returned
EFI_SAL_SUCCESS
The MINSTATE pointer was set for the specified CPU
EFI_SAL_NO_INFORMATION
The specified CPU is not in the database
