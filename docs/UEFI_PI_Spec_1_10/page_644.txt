III-8.2.2.3 EFI_GET_PCD_INFO_PPI.GetSku ()
Summary
Retrieve the currently set SKU Id.
Prototype
typedef
UINTN
(EFIAPI *EFI_GET_PCD_INFO_PPI_GET_SKU) (
VOID
);
Description
GetSku() returns the currently set SKU Id. If the platform has not set at a SKU Id, then the default SKU Id
value of 0 is returned. If the platform has set a SKU Id, then the currently set SKU Id is returned.
