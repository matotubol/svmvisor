InterfaceType
A type of interface that the device being referenced by DeviceIndex is attached to. This field re-uses
Messaging Device Path Node sub-type values as defined by Section “9.3.5 Messaging Device Path” of
UEFI Specification . When more than one sub-type is associated with the interface, sub-type with the
smallest number must be used. For example, InterfaceType must be set to 5 for USB devices.
RemovablaMedia
A flag that indicates if media is removable.
MediaPresent
A flag that indicates if media is present. This flag is always set for non-removable media devices.
ReadOnly
A flag that indicates if media is read-only.
LastBlock
The last logical block that the device supports.
BlockSize
The size of a logical block in bytes. Type EFI_PEI_LBA is defined below.
