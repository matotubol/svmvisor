UEFI Platform Initialization Specification, Release 1.10
typedef struct {
UINT32
RegionAddress;
UINT32
RegionSize;
UINT32
BlockSize;
} EFI_SPI_NOR_FLASH_BLOCK_MAP;
Parameters
RegionAddress
The region starting address, zero value of both RegionAddress and RegionSize indicates the
end of EFI_SPI_NOR_FLASH_BLOCK_MAP array.
RegionSize
The total size of this region, zero value of both RegionAddress and RegionSize indicates the
end of EFI_SPI_NOR_FLASH_BLOCK_MAP array.
BlockSize
The size in bytes of each block in this region.
