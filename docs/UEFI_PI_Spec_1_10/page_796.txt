Description
This function performs the equivalent operation as the SetTime() function in the EFI Runtime Services Table. If
this function is called in virtual mode before any required mapping have been converted to virtual addresses,
then EFI_SAL_VIRTUAL_ADDRESS_ERROR is returned. Otherwise, the one of the status codes defined in the
SetTime() function of the EFI Runtime Services Table is returned.
Status Codes Returned
EFI_SAL_VIRTUAL_ADDRESS_ERROR
This function was called in virtual mode before virtual map-
pings for the specified Extended SAL Procedure are available
Other
See the return status codes for the SetTime function in the EFI
