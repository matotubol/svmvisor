IV-2.2 MM_FOUNDATION_ENTRY_POINT
Summary
This function is the image entry point of a standalone MM Foundation.
Prototype
typedef
VOID
(EFIAPI \*MM_FOUNDATION_ENTRY_POINT) (
IN CONST VOID \* *HobStart*
);
Parameters
HobStart
A pointer to the HOB list.
Description
This function is the image entry point of a standalone MM Foundation. Standalone MM IPL passes* HobStart
to standalone MM Foundation. HOB list that describes the system state at the hand-off to the MM Foundation.
At a minimum, this system state must include the following:
• PHIT HOB
• CPU HOB
• Description of MMRAM
• Description of one or more firmware volumes
MM Foundation can use MMRAM hob to build heap base upon MMRAM hob information. MM Foundation
can use FV hob to dispatch standalone MM driver.
