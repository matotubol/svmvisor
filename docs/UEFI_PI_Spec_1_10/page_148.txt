I-12.3.5.1.2 EFI_PEI_RECOVERY_MODULE_PPI.LoadRecoveryCapsule()
Summary
Loads a DXE capsule from some media into memory and updates the HOB table with the DXE firmware
volume information.
Prototype

General-purpose services that are available to every PEIM. Type EFI_PEI_SERVICES is defined in EFI_
PEI_SERVICES .
This
Indicates the EFI_PEI_RECOVERY_MODULE_PPI instance.
Description
This function, by whatever mechanism, retrieves a DXE capsule from some device and loads it into
memory. Note that the published interface is device neutral.
