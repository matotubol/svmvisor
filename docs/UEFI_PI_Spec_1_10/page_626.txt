III-8.1.1.17 EFI_PCD_PROTOCOL.CancelCallback ()
Summary
Cancels a previously set callback function for a particular PCD token number.
Prototype
typedef
EFI_STATUS
(EFIAPI *EFI_PCD_PROTOCOL_CANCEL_CALLBACK) (
IN CONST EFI_GUID
*Guid, OPTIONAL
IN UINTN

IN EFI_PCD_PROTOCOL_CALLBACK

);
Parameters
Guid
The 128-bit unique value that designates which namespace to monitor. If NULL , use the standard
platform namespace.
CallBackToken
The PCD token number for which to cancel monitoring.
CallBackFunction
The function prototype that was originally passed to the CallBackOnSet function.
Description
Cancels a callback function that was set through a previous call to the CallBackOnSet function.
