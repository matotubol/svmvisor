IN UINTN

IN UINT8
Value
);
Parameters

Number of bytes in Buffer to fill.

None.
I-8.7 Status Code Service
The PEI Foundation publishes the following status code service:
• ReportStatusCode()
This service will report EFI_NOT_AVAILABLE_YET until a PEIM publishes the services for other modules. For
the GUID of the PPI, see EFI_PEI_PROGRESS_CODE_PPI.
