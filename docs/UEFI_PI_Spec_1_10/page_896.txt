);
Parameters
This
A pointer to the EFI_SMBUS_HC_PROTOCOL instance.
Length
Size of the buffer that contains the SMBus device map.
SmbusDeviceMap
The pointer to the device map as enumerated by the SMBus controller driver. Type EFI_SMBUS_
DEVICE_MAP is defined in EFI_PEI_SMBUS_PPI.GetArpMap*() in the *Platform Initialization SMBus PPI
Specification .
Description
The GetArpMap() function returns the mapping of all the SMBus devices that were enumerated by the SMBus
host driver.
Status Codes Returned
EFI_SUCCESS
The SMBus returned the current device map
EFI_UNSUPPORTED
ArpDevice GetArpMap and Notify are not implemented by this

to other drivers that are registered for a callback.
