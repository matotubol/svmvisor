Description
This function performs the equivalent operation as the GetPhysicalAddress() function of the EFI Firmware
Volume Block Protocol. If this function is called in virtual mode before any required mapping have been
converted to virtual addresses, then EFI_SAL_VIRTUAL_ADDRESS_ERROR is returned. Otherwise, the one of
the status codes defined in the GetPhysicalAddress() function of the EFI Firmware Volume Block Protocol is
returned.
Status Codes Returned
EFI_SAL_VIRTUAL_ADDRESS_ERROR
