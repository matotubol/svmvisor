The signed section is an encapsulation section in which the section data is cryptographically signed. To

The signed image is then interpreted as a section stream. EFI_GUID_DEFINED_SECTION2 is used if the section is

III-3.2.5.8 EFI_SECTION_PE32
Summary
A leaf section type that contains a complete PE32+ image.
Prototype
typedef EFI_COMMON_SECTION_HEADER EFI_PE32_SECTION;
typedef EFI_COMMON_SECTION_HEADER2 EFI_PE32_SECTION2;
Description
The PE32+ image section is a leaf section that contains a complete PE32+ image. Normal UEFI executables
are stored within PE32+ images. EFI_PE32_SECTION2 must be used if the section is 16MB or larger.
