II-4.2.4 UEFI Driver Model Example
The following is an UEFI Driver Model example that shows the driver initialization routine for the ABC device
controller that is on the XYZ bus. The EFI_DRIVER_BINDING_PROTOCOL is defined in Chapter 9 of the UEFI
2.0 specification. The function prototypes for the AbcSupported() , AbcStart() , and AbcStop() functions
are defined in Section 9.1 of the UEFI 2.0 specification. This function saves the driver’s image handle and a
pointer to the UEFI Boot Services Table in global variables, so that the other functions in the same driver can
have access to these values. It then creates an instance of the EFI_DRIVER_BINDING_PROTOCOL and installs it
onto the driver’s image handle.
