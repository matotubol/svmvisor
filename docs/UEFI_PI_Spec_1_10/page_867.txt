Description
This function retrieves the MINSTATE pointer specified by Arg3 for the CpuId specified by Arg2 , and calculates
required size specified by Arg4 . If the CPU specified by Arg2 was not registered in system, then EFI_SAL_NO_
INFORMATION is returned. Otherwise, the CPU state buffer related information will be returned, and EFI_
SAL_SUCCESS is returned.
Status Codes Returned
EFI_SAL_SUCCESS
MINSTATE successfully got and size calculated.
EFI_SAL_NO_INFORMATION
The CPU was not registered in system.
