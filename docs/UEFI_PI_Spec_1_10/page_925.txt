AtaData
The data that is returned by an ATA device upon successful completion of the ATA IDENTIFY_DEVICE
command. The IDENTIFY_DEVICE command is defined in the ATA/ATAPI specification. Type EFI_ATA_
IDENTIFY_DATA is defined below.
AtapiData
The data that is returned by an ATAPI device upon successful completion of the ATA IDENTIFY_PACKET_
DEVICE command. The IDENTIFY_PACKET_DEVICE command is defined in the ATA/ATAPI specification.
