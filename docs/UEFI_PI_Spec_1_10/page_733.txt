IV-6.4.2 EFI_PEI_MM_COMMUNICATION_PPI.Communicate()
Summary
Communicates with a registered handler.
Prototype
typedef

*This,

);
Parameters
This
The EFI_PEI_MM_COMMUNICATION_PPI instance.
CommBuffer
Pointer to the buffer to convey into MMRAM.
CommSize
The size of the data buffer being passed in. On exit, the size of data being returned. Zero if the handler
does not wish to reply with any data.
Description
This function provides a service to send and receive messages from a registered PEI service. The EFI_PEI_
MM_COMMUNICATION_PPI driver is responsible for doing any of the copies such that the data lives in
PEI-service-accessible RAM.
A given implementation of the EFI_PEI_MM_COMMUNICATION_PPI may choose to use the EFI_MM_CONTROL_
PPI for effecting the mode transition, or it may use some other method.
The agent invoking the communication interface must be physical/virtually 1:1 mapped.
