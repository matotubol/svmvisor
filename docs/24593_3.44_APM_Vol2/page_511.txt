13.4.2.6  CPU Reference Clocks not Halted
LWP decrements the event counter each reference clock cycle that the CPU is not in a halted state (due 
to STPCLK or a HLT instruction). When the counter becomes negative, it stores a generic event record 
with an EventId of 6.
The reference clock runs at a constant frequency that is independent of the core frequency and of the 
performance state. The reference clock frequency is processor dependent. The processor may 
implement this event by subtracting the ratio of (reference clock frequency / core clock frequency) 
each core clock cycle.
