Operating Modes of the AMD64 Architecture
1.3.1  Long Mode
Long mode consists of two submodes: 64-bit mode and compatibility mode. 64-bit mode supports 
several new features, including the ability to address 64-bit virtual-address space. Compatibility mode 
provides binary compatibility with existing 16-bit and 32-bit applications when running on 64-bit 
system software. 
Throughout this document, references to long mode refer collectively to both 64-bit mode and 
compatibility mode. If a function is specific to either 64-bit mode or compatibility mode, then those 
specific names are used instead of the name long mode.
