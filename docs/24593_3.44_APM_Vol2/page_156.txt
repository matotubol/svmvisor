In the case where a data segment is referenced by the stack selector (SS), the D bit is referred to as the

SP register.
4.7.4  System Descriptors
There are two general types of system descriptors: system-segment descriptors and gate descriptors. 
System-segment descriptors are used to describe the LDT and TSS segments. Gate descriptors do not 
describe segments, but instead hold pointers to code-segment descriptors. Gate descriptors are used for 
protected-mode control transfers between less-privileged and more-privileged software.
System-segment descriptors have the S bit cleared to 0. The type field is used to differentiate the 
various LDT, TSS, and gate descriptors from one another. Table 4-5 summarizes the system-segment 
type-field encodings.
