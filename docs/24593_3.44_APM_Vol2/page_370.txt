9.3.2.4  Machine-Check Status Registers
Each error-reporting register bank includes a machine-check status register (MCi_STATUS) that the 
processor uses to log error information. Hardware writes the status register bits when an error is 
detected, and sets the VAL bit of the register to 1, indicating that the status information is valid. Error 
reporting for the error source associated with the detected error does not need to be enabled in the 
MCi_CTL Register for the processor to write the status register. Error reporting must be enabled for 
the error to be reported via a #MC exception. Software is responsible for clearing the status register 
after the exception has been handled. Attempting to write a value other than 0 to an MCi_STATUS 
register in an implemented MCA bank may raise a general-protection (#GP) exception.
