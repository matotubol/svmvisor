19.1.1  Detecting Support for PQOS
Overall support for the PQOS extension is indicated by CPUID Fn0000_0007_EBX[PQE, PQM] as 
described in Table 19-1.
•
PQM, EBX bit 12. This bit also indicates the PQM-related MSRs are present. (See “PQM MSRs” 
on page 696).
•
PQE, EBX bit 15. This bit also indicates that certain PQE-related MSRs are present. (See “PQOS 
Enforcement (PQE)” on page 708).
19.1.1.1  PQOS Versions

functions. However, some early implementations also use a PQOS version number in addition to 
CPUID. Table 19-2 identifies the PQOS Version associated with a product of a specific
