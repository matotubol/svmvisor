Privilege-Check Examples for Call Gates
In Example 2, all privilege checks fail as follows:
•
The call-gate DPL (DPLG) specifies that only software at privilege-level 0 can access the gate. The
current program does not have enough privilege to access the call gate because its CPL is 2.
•
The selector referencing the call-gate descriptor does not have enough privilege to complete the
reference. Its RPL is numerically greater than DPLG.
