7.4.3  Floating Point Instructions and Memory Types
Uncacheable (UC) and Cache Disable (CD) memory types should not be used with x87, MMX, or 
SIMD (SSE, AVX, and AVX512) instructions. These instructions may read or write a memory location 
multiple times, which can have undesired side effects with these memory types.
