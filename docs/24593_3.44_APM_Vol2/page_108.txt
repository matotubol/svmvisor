3.1.3  CR4 Register
The CR4 register is shown in Figure 3-7. In legacy mode, the CR4 register is identical to the low 32 
bits of the register (CR4 bits 31:0). The features controlled by the bits in the CR4 register are model-
specific extensions. Except for the performance-counter extensions (PCE) feature, software can use 
the CPUID instruction to verify that each feature is supported before using that feature. See 
Section 3.3 “Processor Feature Identification,” on page 71 for information on using the CPUID 
instruction.
