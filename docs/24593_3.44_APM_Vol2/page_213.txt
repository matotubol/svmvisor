1-Gbyte Page Translation—Long Mode 5-Level Paging
Figure 5-32 to Figure 5-34 show the long mode 1-Gbyte translation-table formats (the PML4 and 
PML5 formats are identical to the ones used for 4-Kbyte page translations and are repeated here for 
clarity):
•
Figure 5-32 shows the PML5E (page-map level-5 entry) format.
•
Figure 5-33 shows the PML4E (page-map level-4 entry) format.
•
Figure 5-34 shows the PDPE (page-directory-pointer entry) format.
The fields within these table entries are described in Section 5.4 “Page-Translation-Table Entry 
Fields” on page 153 in the current volume. PTEs and PDEs are not used in 1-Gbyte page translations.
Figure 5-34 on page 153 shows the PDPE.PS bit (bit 7) set to 1, indicating a 1-Gbyte physical-page 
translation.
