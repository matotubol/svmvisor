15.29.9.2  AVIC Access to Un-accelerated vAPIC register
A guest access to an APIC register that is not accelerated by AVIC results in a #VMEXIT with the exit 
code of AVIC_NOACCEL. This fault is also generated if an EOI is attempted when the highest 
priority in-service interrupt is set for level-triggered mode. Additional data associated with this 
#VMEXIT event is returned in the EXITINFO1 and EXITINFO2 fields.
