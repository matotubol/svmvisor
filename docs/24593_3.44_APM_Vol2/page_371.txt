MCi_STATUS Register
The fields within the MCi_STATUS register are:
•
MCA Error Code—Bits 15:0. This field encodes information about the error, including:
-
The type of transaction that caused the error.
-
The memory-hierarchy level involved in the error.
-
The type of request that caused the error.
-
Other information concerning the transaction type.
See the BIOS and Kernel Developer’s Guide (BKDG) or Processor Programming Reference
Manual (PPR)   applicable to your product for information on the format and encoding of the MCA
error code.
•
Model-Specific Extended Error Code—Bits 31:16. This field encodes model-specific information 
about the error. For further information, see the documentation for particular implementations of 
the architecture.
