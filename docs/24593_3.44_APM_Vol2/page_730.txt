17.3.2  Maximum Performance Frequency Clock Count (MPERF)
Specifies the denominator of the effective frequency ratio. The value read is scaled by the TSCRatio 
value (MSR C000_0104h) for guest reads, but the underlying counters are not affected. Reads in host 
mode or writes to MPERF are not affected.
