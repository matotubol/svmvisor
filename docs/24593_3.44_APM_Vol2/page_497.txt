IbsDcMiss (IBS Data Cache Miss)—Bit 7, read/write. This bit is set if the cache line used by the 
tagged load or store operation was not present in the data cache.
•
IbsDcL1tlbHit1G (IBS Data Cache L1 TLB Hit 1-Gbyte Page)—Bit 5, read/write. This bit is set if 
the physical address for the tagged load or store operation was present in a 1-Gbyte page table 
entry in the data cache L1 TLB.
•
IbsDcL1tlbHit2M (IBS Data Cache L1 TLB Hit 2-Mbyte Page)—Bit 4, read/write. This bit is set if 
the physical address for the tagged load or store operation was present in a 2-Mbyte page table 
entry in the data cache L1 TLB.
•
IbsDcL1tlbMiss (IBS Data Cache L1 TLB Miss)—Bit 2, read/write. This bit is set if the physical 
address for the tagged load or store operation was not present in the data cache L1 TLB.
•
IbsStOp (IBS Store Op)—Bit 1, read/write. This bit is set if the tagged op was a store.
•
IbsLdOp (IBS Load Op)—Bit 0, read/write. This bit is set if the tagged op was a load.
IBS Data Cache Linear Address Register (IbsDcLinAd)
Figure 13-26.
IBS Data Cache Linear Address Register (IbsDcLinAd)
IbsDcLinAd[63:0] (IBS Data Cache Linear Address)—Bits 63:0, read/write. Specifies the linear 
address of the tagged op's memory operand. The address is valid only if IbsOpData3[IbsDcLinAdVal] 
is set. The address is in canonical form.
