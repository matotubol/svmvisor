4-Kbyte Page Translation—Long Mode 5-Level Paging
Figures 5-19 through 5-22 on page 144 and Figure 5-23 on page 145 show the long-mode 4-Kbyte 
translation-table formats:
•
Figure 5-19 on page 144 shows the PML5E (page-map level-5 entry) format.
•
Figure 5-20 on page 144 shows the PML4E (page-map level-4 entry) format.
•
Figure 5-21 on page 144 shows the PDPE (page-directory-pointer entry) format.
•
Figure 5-22 on page 144 shows the PDE (page-directory entry) format.
•
Figure 5-23 on page 145 shows the PTE (page-table entry) format.
The fields within these table entries are described in “Page-Translation-Table Entry Fields” on 
page 153.
Figure 5-22 on page 144 shows the PDE.PS bit (bit 7) cleared to 0, indicating a 4-Kbyte physical-page 
translation.
