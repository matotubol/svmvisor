2-Mbyte Page Translation—Long Mode 5-Level Paging
Figures 5-26 through 5-29 on page 149 show the long-mode 2-Mbyte translation-table formats (the 
PML4 and PDPT formats are identical to those used for 4-Kbyte page translations and are repeated 
here for clarity):
•
Figure 5-26 on page 148 shows the PML5E (page-map level-5 entry) format.
•
Figure 5-27 on page 148 shows the PML4E (page-map level-4 entry) format.
•
Figure 5-28 on page 148 shows the PDPE (page-directory-pointer entry) format.
•
Figure 5-29 on page 149 shows the PDE (page-directory entry) format.
The fields within these table entries are described in “Page-Translation-Table Entry Fields” on 
page 153. PTEs are not used in 2-Mbyte page translations.
Figure 5-29 shows the PDE.PS bit (bit 7) set to 1, indicating a 2-Mbyte physical-page translation.
