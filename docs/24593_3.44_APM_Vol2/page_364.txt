Figure 9-1.
MCG_CAP Register
The fields within the MCG_CAP register are:
•
BANK_CNT (MCi Bank Count)—Bits 7:0. This field specifies how many error-reporting register 
banks are supported by the processor implementation.
•
CTLP(MCG_CTL Register Present)—Bit 8. This bit specifies whether or not the Machine-Check 
Global-Control (MCG_CTL) Register is supported by the processor. When the bit is set to 1, the 
register is supported. When the bit is cleared to 0, the register is unsupported. The MCG_CTL 
register is described on page 303.
All remaining bits in the MCG_CAP register are reserved. Writing values to the MCG_CAP register 
produces undefined results.
