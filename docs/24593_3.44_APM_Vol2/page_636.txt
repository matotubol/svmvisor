Logical APIC ID Table Entry
Logical APIC ID Table Format for Flat Mode. When running in flat mode, AVIC expects the 
logical APIC ID table to be formatted as shown in Figure 15-20 below. This mode uses only the first 8 
entries of the table. Although the logical APIC ID is an eight bit value, supported encodings must be of 
the form 2i, where i = 0 to 7. In the figure the value i is used and represents the index into the table. The 
actual byte offset into the table for a given logical APIC ID l_apic_id is 4 * log2(l_apic_id). 
The Logical APIC ID Table is not used by AVIC hardware in x2AVIC mode. Instead, the destination 
logical ID is derived from the target x2APIC ID as follows: Logical x2APICID = (X2APICID[19:4] 
<< 16) | (1 << x2APICID[3:0]).
