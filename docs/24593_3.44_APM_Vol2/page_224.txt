5.6.1  User/Supervisor (U/S) Bit
The U/S bit in the page-translation tables determines the privilege level required to access the page. If 
U/S=0 in any of the page table entries traversed during a table walk, the page is considered a 
supervisor page. If U/S=1 in all the page table entries traversed during a table walk, the page is 
considered a user page. Conceptually, user (non-privileged) pages correspond to a current privilege-
level (CPL) of 3, or least-privileged. Supervisor (privileged) pages correspond to a CPL of 0, 1, or 2, 
all of which are jointly regarded as most-privileged.
