first 1 Mbyte of physical memory. Each 64-bit 
register contains eight type fields for 
characterizing a total of eight memory ranges.

ranges.
•
MTRRfix16K_n characterizes 16 Kbyte 
ranges.
•
MTRRfix4K_n characterizes 4 Kbyte 
ranges.
