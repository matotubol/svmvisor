A.10
Shadow Stack MSRs 
Table A-10 lists the MSRs that support the shadow stack feature. These registers are defined if the 
shadow stack feature is present as indicated by CPUID Fn0000_0007_x0_ECX[CET_SS] (bit 7) =1. 
A.11
Speculation Control MSRs 
Table A-11 lists the MSRs that support speculation control. See “Speculation Control Registers” on 
page 66 for further details, including how to determine whether these registers are defined.
