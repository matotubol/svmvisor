12.2.4  Legacy Task-State Segment
The task-state segment (TSS) is a data structure in memory that the processor uses to save and restore 
the execution state for a task when a task switch occurs. Figure 12-6 on page 373 shows the format of 
a legacy 32-bit TSS.
