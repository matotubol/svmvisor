13.4.2.5  CPU Clocks not Halted
LWP decrements the event counter each clock cycle that the CPU is not in a halted state (due to 
STPCLK or a HLT instruction). When the counter becomes negative, it stores a generic event record 
with an EventId of 5. This counter varies in real-time frequency as the core clock frequency changes.
