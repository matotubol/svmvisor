15.36.19  SEV-SNP Instruction Virtualization
The hypervisor uses RMPUPDATE and PSMASH instructions to modify the RMP when SEV-SNP is 
enabled. In a nested virtualization use case, when the hypervisor is running as a guest, these 
instructions should be replaced with WRMSR  VIRT_RMPUPDATE MSR (C001_F001h) and 
WRMSR VIRT_PSMASH MSR (C001_F002h), respectively.  The VIRT_RMPUPDATE MSR, 
VIRT_PSMASH MSR and CPUID Fn8000_001F_EAX[NestedVirtSnpMsr] (bit 29), which reports 
VIRT_RMPUPDATE and VIRT_PSMASH MSR support, are not implemented in the processor and 
are expected to be emulated by the top-level hypervisor.
VIRT_RMPUPDATE MSR input convention:
RAX: 4KB aligned GPA
RDX: New RMP entry, bytes 7:0
R8: New RMP entry, bytes 15:8
VIRT_RMPUPDATE MSR output convention:
RAX: RMPUPDATE return code
VIRT_PSMASH MSR input convention:
RAX: 2MB aligned GPA
VIRT_PSMASH MSR output convention:
RAX: PSMASH return code
