13.1.1.5  64-Bit-Mode Extended Debug Registers
In 64-bit mode, additional encodings for debug registers are available. The R bit of the REX prefix is 
used to modify the ModRM reg field when that field encodes a control register. These additional 
encodings enable the processor to address DR8–DR15.
Access to the DR8–DR15 registers is implementation-dependent. The architecture does not require 
any of these extended debug registers to be implemented. Any attempt to access an unimplemented 
register results in an invalid-opcode exception (#UD).
13.1.1.6  Debug-Control MSR (DebugCtl)
Figure 13-4 on page 398 shows the format of the debug-control MSR (DebugCtl). DebugCtl provides 
additional debug controls over control-transfer recording and single stepping, and external-breakpoint 
reporting and trace messages. DebugCtl is read and written using the RDMSR and WRMSR 
instructions.
