Logical Destination Register
When an IPI is sent using logical destination mode, all local APICs in the system use the Logical 
Destination Register to determine if the interrupt message is directed to them (see 16.6.1 Receiving 
System and IPI Interrupts). In x2APIC mode, the Logical Destination Register (LDR) is expanded to 
32 bits and contains the ‘logical x2APIC_ID’. System hardware initializes LDR with the 32-bit logical 
x2APIC_ID whenever x2APIC mode is enabled. The LDR is a read-only register located at MSR 
address 080Dh. The format of the Logical Destination Registers is shown in Figure 16-35.
