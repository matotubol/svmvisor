11.4.4.2  FLDENV/FNLDENV and FSTENV Instructions
The FLDENV/FNLDENV and FSTENV instructions load and store only the x87 floating-point 
environment. These instructions, unlike the FSAVE/FNSAVE and FRSTOR instructions, do not save 
or restore the x87 data registers. The FLDENV/FSTENV instructions do not save the full 64-bit data 
and instruction pointers. 64-bit applications should use FXSAVE/FXRSTOR, rather than 
FLDENV/FSTENV. The format of the saved x87 environment images for protected mode and 
real/virtual mode are the same as those of the first 14-bytes of the FSAVE/FNSAVE images for 16-bit 
operands or 32/64-bit operands, respectively. See Figure 11-4 on page 351, Figure 11-5 on page 352,
