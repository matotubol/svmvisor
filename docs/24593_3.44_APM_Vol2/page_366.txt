9.3.1.4  Machine-Check Exception Configuration Register
In addition to the standard Machine Check exception (#MC) signaling, certain machine check events 
can raise an interrupt via the APIC LVT mechanism. Configuration of these interrupts are provided, in 
part, in register MCA_INTR_CFG located at MSR C000_0410, see Figure 9-4. See Section 16.4 
“Local Interrupts” on page 634 for details on configuring LVT entries.
Figure 9-4.
MCA_INTR_CFG Register
9.3.1.5  CPU Watchdog Timer Register
The CPU watchdog timer is used to generate a machine check condition when an instruction does not 
complete within a time period specified by the CPU Watchdog Timer register. The timer restarts the 
count each time an instruction completes, when enabled by the CPU Watchdog Timer Enable bit. The 
time period is determined by the Count Select and Time Base fields. The timer does not count during 
halt or stop-grant.
